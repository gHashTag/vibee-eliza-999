## ⚡ Быстрый тест (5 минут)

### Шаг 1: Подготовка
```bash
# Перейти в директорию
cd /Users/playra/vibee-agent

# Получить API_ID и API_HASH
# 1. Идите на https://my.telegram.org
# 2. Войдите с номером телефона
# 3. Создайте приложение в 'API Development Tools'
```

### Шаг 2: Настроить переменные
```bash
export TELEGRAM_API_ID=ваш_api_id
export TELEGRAM_API_HASH=ваш_api_hash
export TELEGRAM_PHONE=ваш_номер_телефона
```

### Шаг 3: Запустить тест
```bash
# Вариант 1: Скриптом
bash test-gramjs.sh

# Вариант 2: Напрямую
node test-gramjs-api.js
```

### Шаг 4: Тестировать
1. Откройте Telegram
2. Найдите вашего бота/аккаунт
3. Отправьте сообщение `/ping`
4. Проверьте логи

## 🐛 Устранение проблем

### Проблема: "Bot Token not provided"
**Решение:** GramJS не поддерживает ботов! Используйте личный аккаунт.

### Проблема: "API_ID is required"
**Решение:** Получите API_ID на https://my.telegram.org

### Проблема: "Phone number is required"
**Решение:** Установите `TELEGRAM_PHONE`

### Проблема: "Invalid session string"
**Решение:** Удалите сессию и подключитесь заново через телефон
