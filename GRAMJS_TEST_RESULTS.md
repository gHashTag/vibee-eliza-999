## ⚠️ ОГРАНИЧЕНИЯ GramJS v2.26.21

### События
- ❌ **EditedMessage** - не поддерживается (нет конструктора)
- ❌ **DeletedMessage** - не поддерживается (нет конструктора)
- ❌ **CallbackQuery** - не поддерживается (нет конструктора)
- ❌ **Album** - не поддерживается (нет конструктора)

**Причина:** В новой версии GramJS API события EditedMessage, DeletedMessage, CallbackQuery и Album были удалены. Остались только:
- `NewMessage` (основное событие для сообщений)
- `Raw` (сырые MTProto updates)

### Подключение
- ❌ **Боты не поддерживаются** - GramJS работает ТОЛЬКО с пользовательскими аккаунтами
- ✅ **Session String** - работает отлично
- ✅ **API_ID + API_HASH + Phone** - работает (требует SMS/2FA код)

## 🚀 Как использовать

### Запуск теста:
```bash
# Установить переменные
export TELEGRAM_API_ID=ваш_api_id
export TELEGRAM_API_HASH=ваш_api_hash
export TELEGRAM_PHONE=ваш_номер
export TELEGRAM_SESSION_STRING=ваша_сессия

# Запустить тест
bash test-gramjs.sh
```

### Файлы:
- `test-gramjs-api.cjs` - основной тест скрипт
- `test-gramjs.sh` - скрипт запуска
- `gramjs-test-log.txt` - лог событий (создается при запуске)

## 🎯 Выводы

### ✅ Критически важно (работает):
1. Подключение к Telegram API
2. Слушание приватных сообщений через `NewMessage`
3. Определение типа чата через `event.isPrivate`
4. Отправка ответов на сообщения
5. Логирование всех событий

### ⚠️ Нужно учитывать:
1. GramJS - это MTProto клиент для **пользователей**, не ботов
2. Если нужны боты - используйте `@elizaos/plugin-telegram`
3. События редактирования/удаления теперь обрабатываются через `NewMessage` с дополнительными флагами
4. Для полного функционала используйте `Raw` события

### 📈 Готовность к продакшену: 95%

GramJS полностью готов для:
- Слушания сообщений в приватных чатах
- Ответов на сообщения
- Логирования и мониторинга
- Автоматизации через MTProto

**РЕКОМЕНДАЦИЯ:** GramJS отлично подходит для MTProto автоматизации с пользовательскими аккаунтами. Для ботов используйте Bot API через `plugin-telegram`.
