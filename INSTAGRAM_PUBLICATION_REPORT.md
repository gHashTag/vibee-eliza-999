## 🔍 Ключевые особенности

### 1. **Полный цикл автоматизации**

```
Telegram → Character → Instagram Plugin → Meta API → Instagram
   ↓            ↓             ↓             ↓           ↓
  Команда   Определение   Парсинг +      Публикация   Пост
  + Фото    действия      Валидация      через API    готов
```

### 2. **Обработка данных**

**Парсинг сообщений:**
- ✅ URL в тексте
- ✅ Вложения из Telegram
- ✅ Хэштеги (#тег)
- ✅ Подписи (caption)
- ✅ Команды (/instagram, "опубликуй")

**Валидация:**
- ✅ Формат изображений (JPG, PNG, WebP)
- ✅ Размер файла (< 8MB)
- ✅ Разрешение (320px - 1080px)
- ✅ Aspect ratio (1:1, 4:5, 1.91:1)
- ✅ URL (публичный, HTTPS)

### 3. **Облачное хранилище**

**Supabase Storage:**
- ✅ Автоматическая загрузка файлов
- ✅ Генерация уникальных имен
- ✅ Публичные URL
- ✅ Автоочистка (24 часа)

**Fallback режим:**
- ✅ Работа без Supabase
- ✅ Использование прямых URL

### 4. **Meta Business API**

**Автоматизация:**
- ✅ Long-lived токены (60 дней)
- ✅ Проверка токенов при запуске
- ✅ Автообновление

**Публикация:**
- ✅ Создание медиа-контейнера
- ✅ Публикация поста
- ✅ Получение ссылки на пост
- ✅ Сохранение в базу данных

### Переменные Infisical (обязательные)

```bash
INSTAGRAM_ACCESS_TOKEN=...    # Токен Meta Business API
INSTAGRAM_ACCOUNT_ID=...      # ID Instagram аккаунта
```

### Переменные .env (опционально)

```bash
SUPABASE_URL=...                    # Для облачного хранилища
SUPABASE_SERVICE_ROLE_KEY=...       # Для загрузки файлов
```

**Без Supabase:**
- Работает в fallback режиме
- Используются прямые URL изображений
- Файлы не загружаются в облако
