# 🧪 Инструкция по тестированию Instagram Expert

## ✅ Исправления внесены

### 1. Улучшено отображение результата публикации

**БЫЛО ❌**:
```
✅ Пост опубликован в Instagram!
📝 Подпись: [текст]
🖼️ Изображение: [URL]
🔗 Ссылка: https://instagram.com
```

**СТАЛО ✅**:
```
✅ Пост опубликован в Instagram!
📝 Подпись: [текст]
🖼️ Изображение: [URL]

🔗 ID поста: 1234567890123456789
🔗 Ссылка: https://instagram.com/p/1234567890123456789
🔗 Permalink: https://www.instagram.com/p/1234567890123456789/

📱 Telegram ID: 144022504
```

### 2. Добавлено подробное логирование

Теперь в логах видно:
- ✅ `📤 [Instagram] Публикация поста в Instagram...`
- ✅ `📋 [Instagram] Детали поста: { "id": "...", "permalink": "...", "caption": "..." }`
- ✅ `✅ [Instagram] Результат публикации: { ... }`

### 3. Автоматическое получение permalink

После публикации система автоматически запрашивает детали поста у Instagram API и получает:
- `permalink` - прямая ссылка на пост
- `caption` - итоговую подпись с хэштегами
- `timestamp` - время публикации

Открыть ссылку из ответа и убедиться, что пост опубликован.

## 🔧 Что проверить

### ✅ Работает ли:
1. **Распознавание фото** - агент видит приложенное изображение
2. **Загрузка в облако** - файл загружается в Supabase (если настроен)
3. **Публикация** - пост появляется в Instagram
4. **ID поста** - возвращается корректный ID
5. **Ссылка** - permalink работает и открывает пост
6. **Подпись** - текст корректно публикуется с хэштегами

### ❌ Если не работает:
1. **Проверить токены** - INSTAGRAM_ACCESS_TOKEN и INSTAGRAM_ACCOUNT_ID
2. **Проверить права** - токен должен иметь права на публикацию
3. **Проверить URL** - изображение должно быть публично доступно
4. **Посмотреть логи** - все ошибки логируются в консоль

## 🔍 Диагностика проблем

### Проблема: "Не найдено изображение"
**Решение**: Прикрепить фото как файл или указать URL в тексте

### Проблема: "Токены не настроены"
**Решение**: Проверить INSTAGRAM_ACCESS_TOKEN и INSTAGRAM_ACCOUNT_ID в Infisical

### Проблема: "Ошибка API"
**Решение**: Проверить права токена, он должен иметь права на публикацию медиа

### Проблема: Пост не появляется
**Решение**: Проверить логи, возможно ошибка в URL изображения
