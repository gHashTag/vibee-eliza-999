### 3. ✅ ИСПРАВЛЕН LLM API
**Проблема**: `generateText` не экспортируется из `@elizaos/core`
**Решение**: Использован правильный API `runtime.useModel()`
```typescript
// Метод генерации:
private async generateLLMMessage(systemPrompt: string): Promise<string> {
  const response = await this.runtimeRef.useModel('text', {
    prompt: systemPrompt,
    maxTokens: 200,
    temperature: 0.8,
  });
  return response?.trim() || '';
}
```
