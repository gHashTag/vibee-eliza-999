Ошибка: `Failed query: CREATE SCHEMA IF NOT EXISTS migrations`

**Почему это происходит:**
1. VIBEE Agent успешно работает с PostgreSQL базой (порт 3000)
2. KOLS пытается использовать ТУ ЖЕ PostgreSQL базу
3. В базе ЕСТЬ схема migrations (создана VIBEE)
4. НО KOLS не может получить к ней доступ из-за конфликта
5. `@elizaos/server` пытается создать схему заново и падает
