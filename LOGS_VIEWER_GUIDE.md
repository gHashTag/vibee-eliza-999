# 📋 Руководство по просмотру логов VIBEE

## 🎯 Быстрый старт

### Вариант 1: Запуск + Просмотр логов (ВСЕ-В-ОДНОМ)
```bash
./start-and-monitor.sh
```
**Что делает:**
- Запускает всех агентов
- Ожидает инициализацию
- Открывает красивый просмотр логов в multitail

---

## 📊 Скрипты для просмотра логов

### 1. Стандартный просмотр всех логов
```bash
./view-logs.sh
```

**Возможности:**
- ✅ Все 3 агента в одном окне
- ✅ Цветное выделение каждого агента
- ✅ Автоматическое переключение на multitail если доступен
- ✅ Работает без дополнительных зависимостей

**Дополнительные команды:**
```bash
./view-logs.sh vibee      # Только VIBEE агент
./view-logs.sh kols       # Только KOLS агент
./view-logs.sh neuro      # Только NeuroPhoto агент
./view-logs.sh errors     # Только ошибки и предупреждения
./view-logs.sh --help     # Показать справку
```

### 2. Красивый просмотр с multitail
```bash
./view-logs-beautiful.sh
```

**Преимущества:**
- 🎨 Разделенные панели для каждого агента
- 🔵 Синий цвет - VIBEE
- 🟡 Желтый цвет - KOLS
- 🟣 Розовый цвет - NeuroPhoto
- 📊 Одновременный просмотр всех логов

**Требования:**
```bash
brew install multitail  # Автоматически устанавливается при первом запуске
```

## 🚀 Скрипты управления агентами

### Запуск всех агентов
```bash
./start-agents.sh
```

**Что делает:**
- Останавливает старые процессы
- Запускает VIBEE на порту 3000
- Запускает KOLS на порту 3002
- Запускает NeuroPhoto на порту 3003
- Показывает статус и PID процессов

### Остановка всех агентов
```bash
pkill -f 'elizaos'
```

### Проверка статуса агентов
```bash
ps aux | grep elizaos
```

## 🔧 Настройка multitail

### Установка multitail
```bash
# macOS
brew install multitail

# Ubuntu/Debian
sudo apt-get install multitail

# CentOS/RHEL
sudo yum install multitail
```

### Возможности multitail
- 📂 Отдельные панели для каждого файла
- 🔍 Автопрокрутка
- 🏷️ Подсветка синтаксиса
- ⏮️ Прокрутка назад по истории
- 🎨 Цветовое кодирование

## 📱 Практические примеры

./start-agents.sh

## 🛠️ Решение проблем

### Проблема: "multitail не найден"
```bash
# Решение
brew install multitail

# Или используйте стандартный режим
./view-logs.sh
```

### Проблема: "Нет логов"
```bash
# Проверьте что агенты запущены
./start-agents.sh

# Подождите 10-15 секунд для инициализации
sleep 15

# Проверьте файлы логов
ls -la logs/
```

### Проблема: "Агенты не отвечают"
```bash
# Проверьте статус процессов
ps aux | grep elizaos

# Перезапустите агентов
pkill -f 'elizaos'
./start-agents.sh
```

## 📊 Структура логов

### Файлы логов
```
logs/
├── vibee.log        # Логи VIBEE агента
├── kols.log         # Логи KOLS агента
└── neurophoto.log   # Логи NeuroPhoto агента
```

### Что искать в логах

#### VIBEE агент
```bash
# Ищите эти сообщения:
"AgentServer is listening on port 3000"
"Started 1 agents"
"[VIBEE] MessageBusService: Agent is subscribed"
```

#### KOLS агент
```bash
# Ищите эти сообщения:
"AgentServer is listening on port 3002"
"MTProto подключен"
"Проактивное обучение запущено"
```

#### NeuroPhoto агент
```bash
# Ищите эти сообщения:
"AgentServer is listening on port 3003"
"NeuroPhoto plugin initialized"
"Plugin migrations completed"
```

### Цветовая маркировка
- 🟢 **Зеленый** - Успешные операции
- 🟡 **Желтый** - Предупреждения (Warnings)
- 🔴 **Красный** - Ошибки (Errors)
- 🔵 **Синий** - Информационные сообщения (Info)

### Для продакшена
```bash
# 1. Запуск без визуализации
./start-agents.sh

# 2. Мониторинг через системные инструменты
tail -f logs/*.log | grep -i error

# 3. Интеграция с системой мониторинга
```

## 📚 Дополнительные команды

### Просмотр последних строк логов
```bash
# Последние 50 строк из всех логов
tail -50 logs/*.log

# Последние ошибки из VIBEE
tail -100 logs/vibee.log | grep -i error

# Поиск по всем логам
grep -i "error" logs/*.log
grep -i "fail" logs/*.log
grep -i "exception" logs/*.log
```

### Очистка логов
```bash
# Очистить все логи (ВНИМАНИЕ!)
rm logs/*.log

# Очистить только конкретный лог
echo "" > logs/vibee.log
```

### Архивирование логов
```bash
# Создать архив с логами
tar -czf logs-$(date +%Y%m%d-%H%M%S).tar.gz logs/

# Показать размер логов
du -sh logs/*
```

## 🔥 Горячие клавиши

### В multitail
- **q** - Выйти
- **m** - Развернуть/свернуть панель
- **g** / **G** - Перейти к началу/концу
- **Ctrl+F** / **Ctrl+B** - Поиск вперед/назад

### В обычном tail
- **Ctrl+C** - Выйти из просмотра

### В терминале
- **Ctrl+C** - Прервать текущую команду
- **Ctrl+Z** - Приостановить процесс
- **fg** - Продолжить приостановленный процесс
