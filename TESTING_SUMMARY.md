## ⚠️ Важные моменты

### 🚫 GramJS НЕ поддерживает ботов!
Скрипт автоматически подключается через:
1. ✅ Session String (РАБОТАЕТ - рекомендуется)
2. ✅ API_ID + API_HASH + Phone (работает, требует SMS/2FA)
3. ❌ Bot Token (НЕ РАБОТАЕТ - боты не поддерживаются)

### ✅ Для тестирования нужны:
- `TELEGRAM_API_ID` - получаем на https://my.telegram.org
- `TELEGRAM_API_HASH` - получаем на https://my.telegram.org
- `TELEGRAM_PHONE` - номер телефона аккаунта
- Опционально: `TELEGRAM_SESSION_STRING` - для быстрого подключения
