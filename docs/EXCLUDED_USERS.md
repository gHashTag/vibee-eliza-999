# 🚫 Чёрный список пользователей

Пользователи из этого списка **всегда исключаются** из проактивной рассылки фото, независимо от определения пола.

## 📍 Где находится

Файл: `plugin-telegram-craft/src/services/proactiveAvatar.service.ts`

Константа: `EXCLUDED_USERS`

## ➕ Как добавить пользователя в чёрный список

Откройте файл `proactiveAvatar.service.ts` и добавьте username или ID в массив:

```typescript
const EXCLUDED_USERS = new Set<string>([
  "atimukta", // ❌ Мужчина, но получал фото девушки
  "username2", // Добавьте сюда других
  "123456789", // Или по ID
]);
```

## 🔍 Формат

- **Username**: без символа `@`, в нижнем регистре
  - Пример: `"atimukta"` (не `"@atimukta"` и не `"Atimukta"`)
- **User ID**: строка с числовым ID пользователя
  - Пример: `"123456789"`

## ⚠️ Важно

1. После изменений **перезапустите агентов**: `bun dev`
2. Проверка происходит **до** определения пола и анализа аватарки
3. Пользователи из чёрного списка **никогда** не получат проактивные фото
