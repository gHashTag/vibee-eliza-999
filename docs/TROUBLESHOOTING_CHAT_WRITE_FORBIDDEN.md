# 🔧 Решение ошибки `403: CHAT_WRITE_FORBIDDEN`

## 📋 Описание проблемы

Ошибка `403: CHAT_WRITE_FORBIDDEN` возникает, когда юзер-бот пытается отправить сообщение в чат, где у него нет прав на запись.

## 🔍 Причины

1. **Юзер-бот не является администратором группы** - нужны права администратора
2. **Юзер-бот не является участником группы** - нужно сначала присоединиться к группе
3. **В группе включены ограничения** - например, только админы могут писать
4. **Юзер-бот заблокирован в группе** - нужно разблокировать

## ✅ Решения

### 1. Сделать юзер-бота администратором группы

1. Откройте группу в Telegram
2. Перейдите в **Настройки группы** → **Администраторы**
3. Нажмите **Добавить администратора**
4. Найдите аккаунт юзер-бота (по номеру телефона или username)
5. Дайте права:
   - ✅ **Отправка сообщений** (обязательно!)
   - ✅ **Удаление сообщений** (опционально)
   - ✅ **Блокировка участников** (опционально)

### 2. Проверить, что юзер-бот является участником группы

1. Откройте группу в Telegram
2. Проверьте список участников
3. Если юзер-бота нет в списке - добавьте его:
   - Пригласите по ссылке
   - Или добавьте через **Участники** → **Добавить участника**

### 3. Проверить настройки группы

1. Откройте **Настройки группы** → **Права участников**
2. Убедитесь, что **Отправка сообщений** разрешена для всех участников
3. Если включено "Только администраторы" - либо дайте права админа, либо разрешите всем

### 4. Очистить кэш запрещённых чатов

После восстановления прав можно очистить кэш:

```typescript
// В коде или через action
const telegramService = runtime.getService<TelegramService>("telegram-craft");
telegramService?.clearForbiddenChatsCache("chatId"); // Для конкретного чата
// или
telegramService?.clearForbiddenChatsCache(); // Для всех чатов
```

## 🛡️ Автоматическая обработка

Система автоматически:

- ✅ Определяет ошибку `CHAT_WRITE_FORBIDDEN`
- ✅ Добавляет чат в кэш запрещённых чатов
- ✅ Пропускает попытки отправки в запрещённые чаты
- ✅ Логирует предупреждение не чаще раза в минуту (чтобы не спамить)

## 📊 Логи

После исправления вы увидите:

```
✅ [MTProtoAdapter] Message sent successfully
```

Вместо:

```
❌ [MTProtoAdapter] All strategies failed: RPCError: 403: CHAT_WRITE_FORBIDDEN
```

## 🔍 Диагностика

### Проверить текущий статус чата

В логах ищите:

```
⚠️ [MTProtoAdapter] Нет прав на отправку сообщений в чат <chatId>
⚠️ [TelegramService] Чат <chatId> добавлен в кэш запрещённых чатов
```

### Проверить, что юзер-бот видит чат

```bash
# Через action или напрямую
bun scripts/switch-userbot.ts current  # Проверить активную сессию
```

## 💡 Рекомендации

1. **Всегда давайте права администратора** юзер-боту в целевых группах
2. **Проверяйте права перед добавлением** нового чата в конфигурацию
3. **Используйте кэш запрещённых чатов** для предотвращения спама ошибок
4. **Очищайте кэш** после восстановления прав
