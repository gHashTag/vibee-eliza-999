## 🎥 КИНЕМАТОГРАФИЧНЫЕ ТЕХНИКИ

### Camera Movement Vocabulary:

#### Базовые движения:
- **Push-in** — "slow push-in with gentle parallax" (приближение к субъекту)
- **Pull-out** — "smooth pull-back revealing environment" (отдаление)
- **Pan** — "steady pan left to right" (горизонтальное панорамирование)
- **Tilt** — "tilt up from keyboard to face" (вертикальное панорамирование)
- **Dolly zoom** — "dolly zoom emphasizing realization moment" (эффект головокружения)
- **Orbit** — "smooth orbital view around workspace" (круговое движение)

#### Продвинутые техники:
- **Tracking shot** — "tracking shot following gesture"
- **Crane movement** — "crane down from overhead"
- **Whip pan** — "fast whip pan transition"
- **Rack focus** — "rack focus from background to avatar"

### Lens Settings:

**Lens Choices для Sora 2:**
- `50mm f/1.8` - dramatic isolation, strong bokeh
- `35mm f/2.8` - natural perspective, slight background blur
- `24mm f/4` - context, workspace visible
- `85mm f/1.4` - intimate, emotional moments

### Lighting Setups:

**Setup 1: "Golden Hour Tech"**
```
Key: Warm practical light from desk lamp (2700K)
Fill: Cool ambient from window/monitors (5500K)
Rim: Soft RGB edge light (purple/blue gradient)
Effect: Warm subject, cool tech environment contrast
```

**Setup 2: "Hacker Night"**
```
Key: Screen glow as primary source
Fill: Minimal, dark shadows
Rim: Strong colored accent (green/cyan)
Effect: Dramatic, focused, late-night coding vibe
```

**Setup 3: "Startup Morning"**
```

Fill: Soft overhead practical
Rim: None or subtle
Effect: Clean, energetic, productive atmosphere

## 🎨 STYLE GUIDES

### Humor Types по темам:

**Beginner Topics** (00-ВВЕДЕНИЕ, 01-ПЕРВЫЕ-ШАГИ):
- Relatable struggles humor ("We've all been there")
- Before/after comparisons
- Pop culture references (Matrix, Star Wars)
- Self-deprecating coder jokes

**Theory Topics** (02-ТЕОРИЯ-АГЕНТОВ):
- Unexpected analogies (Byzantine generals, bees)
- "Actually..." reveals
- Smart/clever humor, не slapstick
- Visualization gags

**Practical Topics** (04-CLAUDE-CODE):
- Time-saving humor
- Lazy coder jokes (positive spin)
- "This actually works?!" surprise
- Power user flex

**Advanced Topics** (05-ПРОДВИНУТЫЕ-АГЕНТЫ):
- Scale humor (1 → 10 → 100)
- Orchestrator conductor vibes
- Tech aesthetics (cyber, hacker, control room)
- "Am I God?" power moments

### Emoji Strategy:

- **Hook**: Использовать 1 эмодзи для immediate visual hook
- **Mid-video**: Минимальные, только для emphasis
- **Punchline**: 1-2 эмодзи для satisfaction/payoff
- **Never**: Более 3 эмодзи за весь рилс (выглядит спамно)

## 🚀 НОВЫЙ PRODUCTION WORKFLOW

### Sora 2 Visual-First Pipeline:

**Шаг 1: Концепция**
- Выбрать эмоцию (frustration, shock, triumph)
- Определить physical comedy элемент
- Проверить универсальность (понятно ли без контекста?)

**Шаг 2: Timeline Prompting**
- Использовать агента sora2-visual-content-creator
- Или создать Timeline Prompt по template
- Фокус на 6-8 секундах для максимальной retention

**Шаг 3: Sora 2 Generation**
- Вставить Timeline Prompt в Sora 2
- Settings: 720x1280, 6-8s, 24fps
- Generate до получения perfect take

**Шаг 4: Minimal Post-Production**
- ❌ Никаких субтитров/текста поверх
- ✅ Только music bed и sound effects
- ✅ Color grading для mood enhancement
- ✅ Final frame optimization для screenshots

**Шаг 5: Viral Optimization**
- First frame должен stop scroll
- Final frame должен быть shareable
- Check: понятно ли без звука?
- Test: хочется ли показать другу?

### Success Metrics:
- **Share rate > 3%** (очень высокий для educational)
- **Watch through rate > 80%** (full video watched)
- **Comments: "This is me!"** (identification)
- **Saves rate > 5%** (want to show friends later)
