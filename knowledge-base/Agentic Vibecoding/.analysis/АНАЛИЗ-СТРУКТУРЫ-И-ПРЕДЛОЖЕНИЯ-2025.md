## 🌐 ИССЛЕДОВАНИЕ ТРЕНДОВ VIBECODING 2025

### 📈 Ключевые находки:

#### **1. Vibe Coding vs Agentic Coding**
- **Vibe Coding** — интуитивная разработка через prompt-based диалог с AI
- **Agentic Coding** — автономная разработка через goal-driven агентов
- **Популяризатор:** Andrej Karpathy (февраль 2025)

#### **2. Статистика adoption 2025:**
- **78%** команд уже интегрировали AI-инструменты в разработку (GitLab)
- **25%** стартапов Y Combinator имеют кодовую базу на 95% AI-generated
- **25%** компаний внедрят agentic AI пилоты в 2025 (Deloitte)
- **33%** enterprise приложений будут иметь agentic AI к 2028 (Gartner)

#### **3. Популярные инструменты 2025:**
- **Cursor** — AI-powered IDE (форк VSCode)
- **Replit Agent** — браузерная IDE с Agent 3 (200 минут автономности)
- **Claude Code** — CLI tool для terminal-based разработки
- **Salesforce Agentforce Vibes** — enterprise vibe-coding (октябрь 2025)

#### **4. Топ influencers 2025:**

**Twitter/X:**
- **Allie K. Miller** (1.5M подписчиков) — AI бизнес-стратегия (Amazon, IBM)
- **Andrew Ng** (2.1M подписчиков) — основатель DeepLearning.AI, Coursera
- **Kane Kallaway** — основатель sandcastles.ai (content storytelling agent)
- **Francois Chollet** (249K) — Google Research, создатель Keras
- **Demis Hassabis** (128K) — CEO DeepMind

**LinkedIn:**
- **Pascal Bornet** — 20+ лет в AI, ex-McKinsey/EY, CDO Aera Technology
- **Andrew Ng** — Landing AI, DeepLearning.AI

#### **5. Фреймворки для агентов 2025:**

**LangChain/LangGraph** (лидер по adoption):
- Stateful graphs, цепочки промптов
- LangGraph — agents as state machines
- Используется для complex multi-step workflows

**CrewAI** (быстрый рост):
- Role-based multi-agent orchestration
- Простая командная работа агентов (Planner, Coder, Critic)
- Rapid prototyping, content pipelines, BI automation

**AutoGen (Microsoft)**:
- Conversation-first framework
- Agents communicate in natural language
- Structured multi-agent collaboration

**AutoGPT & BabyAGI**:
- Autonomous, self-directed agents
- Push frontier of agent autonomy

#### **6. Вызовы и ограничения:**
- Агенты **struggle** с novel complex problems
- Multi-file projects, poorly documented libraries
- Critical code с real-world impacts
- **Cost challenges:** $300+ на задачу
- **Claude Code:** 4x дороже Cursor Agent (при тех же моделях)
