# 📚 БИБЛИЯ СОЗДАНИЯ АГЕНТОВ

## 🎯 Что это?

**Библия Создания Агентов** - это полное руководство по созданию Telegram-агентов на базе успешного опыта разработки KOLS агента. Создано на основе реальных исправлений и работающих примеров.

## 🚀 Основные принципы

### ✅ ПРАВИЛЬНО
- **ТОЛЬКО LLM генерация** - никаких статических сообщений!
- **Infisical Cloud** - все секреты загружаются из облака
- **Фильтр групп** - обрабатываем только целевые группы
- **TypeScript** - строгая типизация обязательна
- **Логирование** - логируем всё для отладки
- **Тестирование** - тестируем перед продакшеном

### ❌ НЕПРАВИЛЬНО
- Статические fallback сообщения
- API ключи в .env файлах
- Игнорирование нецелевых групп
- Использование `any` типов
- Отсутствие логов
- Работа без тестов

## 🔥 Главные правила

1. **НИКОГДА не добавляйте API ключи в .env** - только Infisical Cloud!
2. **ВСЕГДА используйте LLM** - никаких статических сообщений!
3. **ФИЛЬТРУЙТЕ группы** - безопасность превыше всего!
4. **ЛОГИРУЙТЕ всё** - для легкой отладки!
5. **ТЕСТИРУЙТЕ тщательно** - перед запуском!
