# 📊 ЛОГИ - ПОЛНОЕ РУКОВОДСТВО

## 🎯 Зачем нужны логи?

Логи - это главный инструмент отладки агентов. Они показывают:
- Статус подключения к сервисам
- Обработку сообщений
- Ошибки и их причины
- Генерацию LLM ответов
- Состояние базы данных

## 📂 Где хранятся логи?

### Основные файлы логов:

```
/Users/playra/vibee-agent/logs/
├── kols-llm-working.log           # Логи KOLS агента
├── kols-SECURITY-FIXED.log        # Логи KOLS с фиксами
├── kols-LIVE-MENTOR.log           # Логи KOLS в live режиме
├── vibee-client.log               # Логи VIBEE клиента
└── agent.log                      # Общие логи агентов
```

### Как узнать какой файл логов использовать?

```bash
# Найти все файлы логов
ls -lah /Users/playra/vibee-agent/logs/

# Проверить размер и дату последнего изменения
ls -lah /Users/playra/vibee-agent/logs/*.log
```

## 🔎 Фильтрация логов - ПОЛЕЗНЫЕ ПРИМЕРЫ

### Поиск ошибок

```bash
# Все ошибки (регистронезависимо)
tail -f logs/kols-llm-working.log | grep -i "error\|❌\|failed"

# Только ошибки
tail -f logs/kols-llm-working.log | grep -i "error"

# Только критические ошибки
tail -f logs/kols-llm-working.log | grep "❌"
```

### Поиск LLM генерации

```bash
# Все что связано с LLM
tail -f logs/kols-llm-working.log | grep -i "llm\|генерир"

# Только генерацию
tail -f logs/kols-llm-working.log | grep -i "генерирую"

# Только успешные генерации
tail -f logs/kols-llm-working.log | grep -i "✅.*генерир"
```

### Поиск целевых групп

```bash
# Все сообщения от целевых групп
tail -f logs/kols-llm-working.log | grep "TARGET"

# Сообщения которые пропущены (нецелевые группы)
tail -f logs/kols-llm-working.log | grep "SKIP"

# Все сообщения (входящие)
tail -f logs/kols-llm-working.log | grep "Message event"
```

### Поиск MTProto подключения

```bash
# Подключение к Telegram
tail -f logs/kols-llm-working.log | grep -i "mtproto\|подключ"

# Статус подключения
tail -f logs/kols-llm-working.log | grep -E "✅|❌"
```

### Поиск базы данных

```bash
# Все что связано с БД
tail -f logs/kols-llm-working.log | grep -i "database\|postgres\|sqlite"

# Миграции
tail -f logs/kols-llm-working.log | grep -i "migration"
```

## 🚨 Алерты - когда что-то пошло не так

### Проверка что агент работает

```bash
# Проверить что процесс запущен
ps aux | grep "kolsAgent\|myagent" | grep -v grep

# Проверить что логи обновляются
tail -f logs/kols-llm-working.log &
sleep 5
kill %1  # Остановить tail

# Проверить последние сообщения
tail -20 logs/kols-llm-working.log | grep -E "✅|❌|🤖"
```

### Быстрая проверка статуса

```bash
# ОДНА КОМАНДА для проверки всего:
echo "=== PROCESS ===" && \
ps aux | grep "kolsAgent" | grep -v grep && \
echo -e "\n=== LAST 5 LINES ===" && \
tail -5 logs/kols-llm-working.log && \
echo -e "\n=== ERRORS LAST HOUR ===" && \
grep -i "error" logs/kols-llm-working.log | tail -5 && \
echo -e "\n=== LLM LAST 5 ===" && \
grep -i "генерирую" logs/kols-llm-working.log | tail -5
```

## 📱 Мониторинг через скрипты

### Создать скрипт мониторинга

Создать `monitor-agent.sh`:

```bash
#!/bin/bash

AGENT_NAME="kols-llm-working"
LOG_FILE="logs/${AGENT_NAME}.log"

echo "📊 Мониторинг ${AGENT_NAME}"
echo "=================================="
echo ""

while true; do
    clear
    echo "📊 Мониторинг ${AGENT_NAME} - $(date)"
    echo "=================================="
    echo ""

    echo "🔄 ПРОЦЕСС:"
    ps aux | grep "${AGENT_NAME}" | grep -v grep || echo "❌ Не найден"
    echo ""

    echo "📝 ПОСЛЕДНИЕ 5 СТРОК:"
    tail -5 ${LOG_FILE}
    echo ""

    echo "❌ ОШИБКИ (последние 3):"
    grep -i "error" ${LOG_FILE} | tail -3 || echo "Нет ошибок"
    echo ""

    echo "🤖 LLM ГЕНЕРАЦИЯ (последние 3):"
    grep -i "генерирую" ${LOG_FILE} | tail -3 || echo "Нет генераций"
    echo ""

    echo "Обновится через 5 секунд... (Ctrl+C для выхода)"
    sleep 5
done
```

Сделать исполняемым и запустить:

```bash
chmod +x monitor-agent.sh
./monitor-agent.sh
```

## 🎯 Чек-лист проверки логов

### При запуске агента

- [ ] Процесс запущен (`ps aux`)
- [ ] Логи начали записываться (`tail -f`)
- [ ] MTProto подключился (`✅ MTProto подключен!`)
- [ ] База данных подключена (`DatabaseMigrationService`)
- [ ] Плагины загружены (`Plugin migrations completed`)
- [ ] Нет критических ошибок (`❌`)

### При получении сообщения

- [ ] Сообщение получено (`📨 Message event received`)
- [ ] Группа в целевом списке (`[TARGET]` или `[SKIP]`)
- [ ] Начата LLM генерация (`🤖 Генерирую ответ...`)
- [ ] Ответ сгенерирован (`✅ Ответ сгенерирован`)
- [ ] Ответ отправлен (`✅ Сообщение отправлено`)

### При ошибках

- [ ] Ошибка залогирована (`❌ Ошибка...`)
- [ ] Указана причина ошибки
- [ ] Нет критических ошибок в цикле
- [ ] Агент продолжает работать
