# План ручного тестирования Owner Notifications

## Обзор

Тестирование системы уведомлений владельцу бота (OWNER_CHAT_ID = 144022504).

---

## Предварительные условия

1. **Бот запущен:**
   ```bash
   cd /Users/playra/vibee-agent && bun dev
   ```

2. **Владелец авторизован** в Telegram с ID `144022504`

3. **Тестовая группа** настроена в `TARGET_CHATS` (например, 2643951085)

4. **Секреты загружены** из Infisical:
   - `TELEGRAM_BOT_TOKEN`
   - `FAL_KEY` или `REPLICATE_API_KEY`

## Тест 1: Уведомление о новом пользователе

### Сценарий
Новый пользователь впервые запрашивает генерацию фото.

### Шаги
1. Найти пользователя, который **ещё не использовал** NeuroPhoto
2. Попросить его написать в группу: `"сделай из моей аватарки фото супермена"`
3. Дождаться генерации фото

### Ожидаемый результат
Владелец (144022504) получает сообщение:
```
👤 НОВЫЙ ПОЛЬЗОВАТЕЛЬ

User ID: [telegram_id]
Username: @[username]
Имя: [firstName]

Впервые использует NeuroPhoto!
```

### Проверка в логах
```bash
tail -f /Users/playra/vibee-agent/logs/vibee.log | grep -i "notify.*new_user"
```

## Тест 5: Негативный сценарий - Ошибка отправки

### Сценарий
Проверить, что ошибки отправки уведомлений не ломают основной флоу.

### Шаги
1. Временно изменить `OWNER_CHAT_ID` на несуществующий ID
2. Запустить генерацию фото
3. Убедиться, что фото сгенерировалось несмотря на ошибку уведомления

### Ожидаемый результат
- Фото сгенерировано и отправлено пользователю
- В логах ошибка: `Failed to notify owner`
- Бот продолжает работать
