# 📚 Плагин Knowledge для ElizaOS - Полная документация

## Что такое плагин Knowledge?

Плагин Knowledge добавляет ИИ-агенту способность обучаться на документах и отвечать на вопросы на их основе. Работает из коробки с нулевой настройкой.

## Установка и первая настройка

### Шаг 1: Добавление плагина

Добавьте плагин в список `plugins` в файле персонажа:

```typescript
export const character = {
  name: "MyAgent",
  plugins: [
    "@elizaos/plugin-openai", // Обязательно
    "@elizaos/plugin-knowledge", // Добавить эту строку
    // ... другие плагины
  ],
};
```

**Требования:**

- Обязательно нужен `OPENAI_API_KEY` в файле `.env` для создания эмбеддингов
- Нужен хотя бы один AI-провайдер плагин (например, `@elizaos/plugin-openai`)

### Шаг 2: Автозагрузка документов при запуске (опционально)

1. **Создайте папку `docs/` в корне проекта:**

```
your-project/
├── .env
├── docs/
│   ├── guide.pdf
│   ├── manual.txt
│   └── notes.md
└── package.json
```

2. **Добавьте в `.env`:**

```env
LOAD_DOCS_ON_STARTUP=true
```

3. **Запустите агента** - он автоматически изучит все документы из папки `docs`

## Использование

### Веб-интерфейс

1. Запустите агента: `elizaos start`
2. Откройте браузер: `http://localhost:3000`
3. Выберите агента → вкладка Knowledge
4. Функции:
   - Загрузка новых документов
   - Поиск существующих документов
   - Удаление ненужных документов
   - Просмотр всех изученных документов
   - **Можно перетаскивать файлы прямо на вкладку Knowledge**

### Чат с агентом

После загрузки документов просто общайтесь с агентом естественно:

- "What does the guide say about setup?"
- "Search your knowledge for configuration info"
- "What do you know about [any topic]?"

### Действия агента

Агент автоматически получает способности:

- **PROCESS_KNOWLEDGE** - "Remember this document: [file path or text]"
- **SEARCH_KNOWLEDGE** - "Search your knowledge for [topic]"

### Примеры в чате:

```
You: What were the Q3 revenue figures?
Agent: Based on the Q3 earnings report in my knowledge base, the revenue was $2.3M,
       representing a 15% increase from Q2...

You: Search your knowledge for information about profit margins
Agent: I found relevant information about profit margins: The Q3 report shows gross
       margins improved to 42%, up from 38% in the previous quarter...
```

## Поддерживаемые форматы файлов

- **Текстовые файлы:** `.txt`, `.md`, `.csv`, `.json`, `.xml`, `.yaml`
- **Документы:** `.pdf`, `.doc`, `.docx`
- **Файлы кода:** `.js`, `.ts`, `.py`, `.java`, `.cpp`, `.html`, `.css` и многие другие

## Дополнительная настройка

### Кастомная папка для документов

В файле `.env`:

```env
KNOWLEDGE_PATH=/path/to/your/documents
```

### Настройки для OpenRouter

В файле персонажа:

```typescript
export const character = {
  name: "MyAgent",
  plugins: [
    "@elizaos/plugin-openrouter",
    "@elizaos/plugin-openai", // Обязательно для эмбеддингов
    "@elizaos/plugin-knowledge",
  ],
};
```

В файле `.env`:

```env
OPENROUTER_API_KEY=your-openrouter-api-key
OPENAI_API_KEY=your-openai-api-key
```

**Важно:** Плагин автоматически использует OpenAI эмбеддинги даже при использовании OpenRouter для генерации текста.

## Часто задаваемые вопросы

**Q: Нужны ли API ключи?**
A: Для простой настройки только OPENAI_API_KEY.

**Q: Что если у меня нет AI плагинов?**
A: Нужен хотя бы один AI-провайдер плагин (например, `@elizaos/plugin-openai`) для эмбеддингов.

**Q: Можно ли загружать документы во время работы агента?**
A: Да! Через веб-интерфейс или скажите агенту обработать файл.

**Q: Сколько это стоит?**
A: Только стоимость создания эмбеддингов (обычно копейки за документ).

**Q: Где хранятся документы?**
A: Документы обрабатываются и хранятся в базе данных агента как поисковые фрагменты.

## Решение проблем

### Документы не загружаются

Проверьте:

- Папка `docs` существует в правильном месте
- `LOAD_DOCS_ON_STARTUP=true` в файле `.env`
- Файлы в поддерживаемых форматах

### Нет доступа к веб-интерфейсу

Проверьте:

- Агент запущен (`elizaos start`)
- Правильный URL: `http://localhost:3000`
- Порт 3000 не занят другим приложением

### Агент не может найти информацию

Попробуйте:

- Использовать более простые поисковые термины
- Проверить, был ли документ успешно обработан
- Проверить вкладку Knowledge, что документ там есть
