## 🤖 AI и Агенты

### AI-Агент

**Определение:** Автономная программа, способная воспринимать окружающую среду, принимать решения и выполнять действия для достижения целей.

**Пример:** ChatGPT, Claude, автопилот Tesla — все это разные виды AI-агентов.

### Агент (Agent)

**Определение:** В контексте программирования — сущность, которая может автономно выполнять задачи, взаимодействовать с окружением и принимать решения.

**Типы агентов:**

- Simple Reflex Agent
- Model-Based Agent
- Goal-Based Agent
- Utility-Based Agent
- Learning Agent

### Автономность (Autonomy)

**Определение:** Способность агента действовать самостоятельно без постоянного вмешательства человека.

**Пример:** Агент автоматически проверяет почту каждые 5 минут и отправляет уведомления о важных письмах.

### Субагент (Subagent)

**Определение:** Специализированный агент, который выполняет конкретные подзадачи в рамках более крупной системы.

**Пример:** В системе управления проектами один субагент отвечает за планирование, другой — за тестирование.

## 🧠 Типы Агентов

### Simple Reflex Agent

**Определение:** Простейший тип агента, который реагирует на текущее состояние окружения по принципу "если-то" (if-then).

**Пример:** Терморегулятор включает обогрев, если температура < 20°C.

### Model-Based Reflex Agent

**Определение:** Агент, который поддерживает внутреннюю модель мира для принятия решений.

**Пример:** Робот-пылесос запоминает карту дома и планирует маршрут уборки.

### Goal-Based Agent

**Определение:** Агент, который планирует последовательность действий для достижения заданной цели.

**Пример:** AI-агент для написания кода анализирует требования и пошагово создаёт программу.

### Utility-Based Agent

**Определение:** Агент, который оптимизирует свои действия для максимизации функции полезности.

**Пример:** Инвестиционный бот балансирует риски и доходность для максимального профита.

### Learning Agent

**Определение:** Агент, который улучшает свою производительность через опыт и обратную связь.

**Пример:** Рекомендательная система Netflix учится на ваших предпочтениях.

### LLM-Based Agents

**Определение:** Агенты, построенные на основе больших языковых моделей (Large Language Models).

**Примеры:** Claude Code, GitHub Copilot, ChatGPT API агенты.

## 🛠️ Технические Термины

### API (Application Programming Interface)

**Определение:** Интерфейс для взаимодействия между различными программами или сервисами.

**Пример:** OpenAI API позволяет интегрировать GPT в ваше приложение.

### API Key

**Определение:** Уникальный токен для аутентификации при работе с API.

**Безопасность:** Никогда не публикуйте API ключи в открытом коде!

### CLI (Command Line Interface)

**Определение:** Интерфейс командной строки для взаимодействия с программами через текстовые команды.

**Примеры:** Terminal на macOS, Command Prompt на Windows, Bash на Linux.

### Environment Variable

**Определение:** Переменная окружения, которая хранит конфигурационные данные системы или приложения.

**Пример:** `API_KEY=your_secret_key` — безопасный способ хранения секретных данных.

### Git

**Определение:** Система контроля версий для отслеживания изменений в коде.

**Основные команды:** `git add`, `git commit`, `git push`, `git pull`.

### Hook

**Определение:** Точка в программе, где можно "зацепить" пользовательский код для выполнения при определённых событиях.

**Пример:** Git hooks выполняются автоматически при коммите.

### HTML

**Определение:** HyperText Markup Language — язык разметки для создания веб-страниц.

### JavaScript

**Определение:** Язык программирования для создания интерактивных веб-приложений.

### Node.js

**Определение:** Среда выполнения JavaScript вне браузера, позволяющая создавать серверные приложения.

### NPM

**Определение:** Node Package Manager — менеджер пакетов для JavaScript, позволяющий устанавливать библиотеки.

**Команды:** `npm install`, `npm run`, `npm start`.

### MCP

**Определение:** Model Context Protocol — протокол для взаимодействия AI моделей с внешними инструментами и данными.

### Webhook

**Определение:** HTTP-коллбэк, который автоматически вызывается при определённых событиях.

**Пример:** GitHub отправляет webhook при каждом push в репозиторий.

## 🔧 Концепции и Паттерны

### Agent Function (Агентная функция)

**Определение:** Функция, которая принимает состояние окружения и возвращает действие агента.

```javascript
function agentFunction(perception) {
  // Анализ восприятия
  // Принятие решения
  return action;
}
```

### Agentic Workflows

**Определение:** Рабочие процессы, где AI-агенты автономно выполняют последовательности задач.

**Пример:** Агент автоматически собирает данные → анализирует → создаёт отчёт → отправляет по email.

### Chain of Thought (CoT)

**Определение:** Метод, где AI модель пошагово объясняет свои рассуждения.

**Пример:** "Сначала я проанализирую требования, затем выберу подходящую архитектуру, потом напишу код."

### Checkpoint

**Определение:** Точка сохранения состояния системы для возможности восстановления.

### Context Window

**Определение:** Максимальное количество токенов, которое AI модель может обработать за один раз.

**Примеры:** GPT-4: ~32K токенов, Claude-3: ~200K токенов.

### Deploy (Деплой)

**Определение:** Процесс развёртывания приложения в производственную среду.

### Large Language Models (LLM)

**Определение:** Большие языковые модели — AI системы, обученные на огромных объёмах текста.

**Примеры:** GPT-4, Claude-3, LLaMA, Gemini.

### Perception (Восприятие)

**Определение:** Способность агента получать информацию из окружающей среды.

**Примеры:** Чтение файлов, API запросы, анализ пользовательского ввода.

### Planning (Планирование)

**Определение:** Процесс создания последовательности действий для достижения цели.

### ReAct Pattern

**Определение:** Паттерн Reasoning + Acting — агент чередует рассуждения и действия.

**Схема:** Думать → Действовать → Наблюдать → Думать → Действовать...

### Temperature

**Определение:** Параметр, контролирующий "креативность" AI модели (от 0 = детерминированно до 1 = очень креативно).

### Tokens (Токены)

**Определение:** Базовые единицы текста, которые обрабатывает AI модель.

**Примерно:** 1 токен ≈ 0.75 слова в английском языке.

### Tool Calling (Вызов инструментов)

**Определение:** Способность AI агента использовать внешние инструменты и API.

**Примеры:** Вызов калькулятора, поиск в интернете, выполнение кода.

## 🖥️ Терминология Разработки

### Terminal (Терминал)

**Определение:** Интерфейс командной строки для выполнения текстовых команд.

### Variable (Переменная)

**Определение:** Именованное хранилище данных в программе.

```javascript
const myVariable = "Hello, World!";
```

### Function (Функция)

**Определение:** Блок кода, который выполняет определённую задачу.

```javascript
function greet(name) {
  return `Hello, ${name}!`;
}
```

### Реактивная система

**Определение:** Система, которая быстро реагирует на изменения и события.

**Принципы:** Отзывчивость, устойчивость, эластичность, фокус на сообщениях.
