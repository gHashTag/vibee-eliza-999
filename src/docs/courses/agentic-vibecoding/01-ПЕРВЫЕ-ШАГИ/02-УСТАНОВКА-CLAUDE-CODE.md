# Windows (через Chocolatey)
choco install nodejs

# Универсальный способ (через nvm)
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.5/install.sh | bash

### Вариант B: Через API ключ — **Для опытных пользователей**

**⚠️ Внимание:** API дороже для активного использования и требует мониторинга расходов.

**Когда выбирать API:**

- Редкое использование (<10 промптов/день)
- Автоматизация и скрипты
- Интеграция в собственные продукты
- Нужен программный доступ

**Шаг 1: Получите API ключ**

1. Перейдите на https://console.anthropic.com/
2. Зарегистрируйтесь/войдите
3. Перейдите в Settings → API Keys
4. Создайте новый API ключ
5. **⚠️ Скопируйте ключ сразу** (показывается только один раз!)

**Шаг 2: Настройте переменные окружения**

```bash
# Установите ключ в переменные окружения
export ANTHROPIC_API_KEY="sk-ant-api03-..."

# Или сохраните в ~/.zshrc для постоянного использования
echo 'export ANTHROPIC_API_KEY="sk-ant-api03-..."' >> ~/.zshrc
source ~/.zshrc

# Проверьте, что ключ установлен
echo $ANTHROPIC_API_KEY
# Должен вывести: sk-ant-api03-...
```

**Шаг 3: Запуск Claude Code с API**

```bash
# Запуск CLI (использует ANTHROPIC_API_KEY автоматически)
claude

# Ожидаемый вывод:
✓ Using API key authentication
✓ Model: Claude 3.5 Sonnet
✓ Pay-as-you-go pricing
```

**Стоимость API (2025):**

| Модель         | Input (за 1M токенов) | Output (за 1M токенов) | Средний промпт |
| -------------- | --------------------- | ---------------------- | -------------- |
| **Sonnet 4.5** | $3                    | $15                    | ~$0.09         |
| **Sonnet 4.1** | $5                    | $25                    | ~$0.15         |
| **Opus 4.1**   | $20                   | $80                    | ~$0.50         |
| **Haiku**      | $0.25                 | $1.25                  | ~$0.01         |

_Средний промпт: 2K input + 1K output_

**Пример расчета стоимости:**

```
Сценарий: 500 промптов/месяц (как Pro план)
Модель: Sonnet 4.5
Средний промпт: 2K input + 1K output

Расчет:
- Input: (500 × 2K) / 1M × $3 = $3
- Output: (500 × 1K) / 1M × $15 = $7.50
Итого: ~$10.50/месяц

Вывод: API дешевле Pro ($20) при легком использовании
Но: нет приоритета, нужен мониторинг расходов
```

**Недостатки API:**

- ⚠️ **Непредсказуемые расходы** (может внезапно вырасти)
- ⚠️ **Низкий приоритет** (медленнее, чем подписки)
- ⚠️ **Нужен мониторинг** (чтобы не улететь в космос по стоимости)
- ⚠️ **Нет ранних фич** (получаете позже, чем Pro/Max)
- ⚠️ **Сложнее настроить** rate limits

**Мониторинг расходов API:**

```bash
# Просмотр usage за текущий месяц
claude --usage

# Вывод:
Month: October 2025
Requests: 234
Input tokens: 456,789
Output tokens: 123,456
Estimated cost: $12.34
```

**💡 Совет:** Установите лимит расходов в консоли Anthropic:

- Console → Settings → Billing → Set spending limit
- Рекомендуется: $50/месяц для начала

## 📋 Базовые Команды Claude Code

### Команды сессии:

| Команда                | Описание                                | Пример                 |
| ---------------------- | --------------------------------------- | ---------------------- |
| `claude`               | Запустить новую сессию                  | `claude`               |
| `claude --new-session` | Начать с чистого листа (без истории)    | `claude --new-session` |
| `claude --continue`    | Продолжить предыдущую сессию            | `claude --continue`    |
| `/exit`                | Выйти из сессии                         | `/exit`                |
| `/clear`               | Очистить экран (не сбрасывает контекст) | `/clear`               |
| `/help`                | Показать список команд                  | `/help`                |

---

### Slash-команды (внутри сессии):

| Команда              | Описание                      | Когда использовать          |
| -------------------- | ----------------------------- | --------------------------- |
| `/help`              | Справка по всем командам      | Забыли синтаксис            |
| `/clear`             | Очистить экран                | Экран переполнен текстом    |
| `/reset`             | Сбросить контекст (новый чат) | AI начал деградировать      |
| `/save`              | Сохранить текущую сессию      | После важной работы         |
| `/load [session-id]` | Загрузить предыдущую сессию   | Вернуться к старому проекту |
| `/config`            | Настройки Claude Code         | Изменить модель, параметры  |
| `/exit`              | Выход                         | Закончили работу            |

## 🐛 Troubleshooting (Решение типичных проблем)

### Проблема 1: "command not found: claude"

**Симптомы:**

```bash
$ claude
zsh: command not found: claude
```

**Решение:**

```bash
# Проверьте, установлен ли пакет
npm list -g @anthropic-ai/claude-code

# Если не установлен, переустановите:
npm install -g @anthropic-ai/claude-code

# Проверьте PATH (где npm устанавливает глобальные пакеты):
npm config get prefix
# Должен быть в PATH: /usr/local или ~/.npm-global

# Добавьте в PATH, если нужно:
echo 'export PATH="$(npm config get prefix)/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
```

## 💡 Советы для эффективной работы

### 1️⃣ Используйте контекстные подсказки:
