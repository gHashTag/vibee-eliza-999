## 🤔 Что такое терминал и зачем он нужен?

### Простое объяснение для новичков:

**Терминал (командная строка) — это текстовый интерфейс управления компьютером.**

**Аналогия:**

- **GUI (графический интерфейс)** = Разговор жестами 👋
- **Терминал** = Четкие текстовые команды 📝

**Почему текст лучше:**

- ⚡ Быстрее: `cd projects` vs 5 кликов мышью
- 🎯 Точнее: команда делает РОВНО то, что вы сказали
- 🤖 Автоматизируемо: скрипты = повторяющиеся команды
- 💪 Мощнее: доступ к функциям, которых нет в GUI

### 🎯 Зачем терминал для VibeCoding?

**1️⃣ Claude Code работает ТОЛЬКО в терминале**

```bash
# Вся магия происходит здесь:
claude → Your AI pair programmer in the terminal
```

**2️⃣ Профессиональные инструменты живут в CLI**

```bash
git       # Система контроля версий
npm       # Менеджер пакетов Node.js
docker    # Контейнеризация
kubectl   # Kubernetes
terraform # Infrastructure as Code
```

**3️⃣ Скорость = Продуктивность**

```bash
# GUI: Открыть Finder → Navigate → Create folder → Create file → Open in editor
# CLI:  mkdir project && cd project && touch index.js && code .

# Время: 30 секунд vs 3 секунды ⚡
```

### ❌ Мифы о терминале

**Миф 1:** _"Терминал — это сложно, только для хакеров"_

- ✅ **Реальность:** 10 команд решают 90% задач. Это как выучить 10 слов на английском.

**Миф 2:** _"Нужно всё запоминать наизусть"_

- ✅ **Реальность:** Tab для автодополнения, `man` для справки, Warp AI для подсказок.

**Миф 3:** _"GUI удобнее и интуитивнее"_

- ✅ **Реальность:** Терминал интуитивнее после недели практики. Попробуйте!

**Миф 4:** _"Можно случайно всё сломать"_

- ✅ **Реальность:** Опасных команд всего 2-3. Мы их отдельно пометим ⚠️

### ✅ Что НУЖНО знать для VibeCoding

**Минимальный набор (5 минут):**

```bash
cd       # Change Directory - перейти в папку
ls       # List - показать содержимое
pwd      # Print Working Directory - где я нахожусь
mkdir    # Make Directory - создать папку
touch    # Создать файл
```

**Этого достаточно, чтобы начать с Claude Code!**

### ❌ Что НЕ нужно (пока) знать:

- Bash/Shell скриптинг
- Системное администрирование
- Продвинутые команды (awk, sed, regex)
- Сетевые утилиты
- Управление процессами

**Фокус:** Научитесь базе, остальное придет естественно через практику.

## 📂 НАВИГАЦИЯ ПО ФАЙЛОВОЙ СИСТЕМЕ

### `pwd` - Где я нахожусь? 📍

```bash
pwd
# Выведет: /home/username/projects
```

**Вайб-совет**: Это как GPS для терминала - всегда знай, где ты находишься!

### `ls` - Что здесь есть? 👀

```bash
ls              # Простой список файлов
ls -la          # Подробная информация + скрытые файлы
ls -lah         # То же самое, но размеры в человекочитаемом формате
```

**Полезные флаги:**

- `-l` - подробный список
- `-a` - показать скрытые файлы (начинаются с точки)
- `-h` - человекочитаемые размеры (KB, MB, GB)
- `-t` - сортировка по времени изменения

### `cd` - Перемещение по директориям 🚶

```bash
cd projects           # Перейти в папку projects
cd ..                 # Подняться на уровень выше
cd ~                  # Перейти в домашнюю директорию
cd /                  # Перейти в корень системы
cd -                  # Вернуться в предыдущую директорию
```

**Лайфхак**: Используй Tab для автодополнения имен файлов и папок!

## 📝 РАБОТА С ФАЙЛАМИ И ПАПКАМИ

### `mkdir` - Создание директорий 📁

```bash
mkdir my-project                    # Создать одну папку
mkdir -p projects/web/frontend     # Создать вложенные папки
```

### `touch` - Создание файлов ✨

```bash
touch index.html                    # Создать пустой файл
touch style.css script.js          # Создать несколько файлов
```

### `cp` - Копирование 📋

```bash
cp file.txt backup.txt              # Копировать файл
cp -r folder/ folder-copy/          # Копировать папку рекурсивно
```

### `mv` - Перемещение и переименование 🔄

```bash
mv old-name.txt new-name.txt       # Переименовать файл
mv file.txt /home/user/documents/  # Переместить файл
```

### `rm` - Удаление (ОСТОРОЖНО!) ⚠️

```bash
rm file.txt                         # Удалить файл
rm -r folder/                       # Удалить папку и всё содержимое
rm -rf folder/                      # Принудительное удаление (БЕЗ ПОДТВЕРЖДЕНИЯ!)
```

**⚠️ ВАЖНО**: `rm -rf` - это команда без права на ошибку! Удаленное не восстановить!

## 📖 ПРОСМОТР СОДЕРЖИМОГО ФАЙЛОВ

### `cat` - Вывести весь файл 🐱

```bash
cat file.txt                        # Показать содержимое файла
cat file1.txt file2.txt            # Показать несколько файлов подряд
```

### `less` / `more` - Постраничный просмотр 📄

```bash
less large-file.log                 # Открыть файл для чтения
# Навигация в less:
# Space - следующая страница
# b - предыдущая страница
# / - поиск
# q - выход
```

### `head` / `tail` - Начало и конец файла 🔝🔚

```bash
head -n 10 file.txt                # Первые 10 строк
tail -n 20 file.txt                # Последние 20 строк
tail -f app.log                    # Следить за обновлениями файла в реальном времени
```

## 🔍 ПОИСК И ФИЛЬТРАЦИЯ

### `grep` - Поиск текста 🔎

```bash
grep "error" log.txt               # Найти строки с "error"
grep -i "error" log.txt           # Игнорировать регистр
grep -r "TODO" ./                 # Рекурсивный поиск в папке
grep -n "function" script.js      # Показать номера строк
```

### `find` - Поиск файлов 🔦

```bash
find . -name "*.js"                # Найти все JS файлы
find . -type d -name "node_modules" # Найти все папки node_modules
find . -mtime -7                   # Файлы измененные за последние 7 дней
```

## 🔧 СИСТЕМНЫЕ КОМАНДЫ

### `echo` - Вывод текста 📢

```bash
echo "Hello, World!"                # Простой вывод
echo $PATH                         # Вывести значение переменной
echo "text" > file.txt             # Записать в файл (перезапись)
echo "more text" >> file.txt      # Добавить в конец файла
```

### `which` - Где находится программа? 📍

```bash

```

### `ps` - Список процессов 📊

```bash
ps                                  # Процессы текущего терминала
ps aux                             # Все процессы в системе
```

### `kill` - Завершение процессов ☠️

```bash
kill 1234                          # Завершить процесс с PID 1234
kill -9 1234                       # Принудительное завершение
```

## 🎨 ПОЛЕЗНЫЕ КОМБО И ПАЙПЫ

### Pipe `|` - Конвейер команд 🔗

```bash
ls -la | grep ".txt"               # Показать только .txt файлы
cat file.txt | grep "error" | wc -l # Подсчитать количество ошибок
history | grep "git"               # Найти git команды в истории
```

### Перенаправление вывода `>` и `>>` 📤

```bash
ls -la > files.txt                 # Сохранить список файлов
echo "New line" >> log.txt        # Добавить строку в конец файла
command 2> errors.txt             # Перенаправить ошибки в файл
```

## 🤔 ТЕРМИНАЛ ДЛЯ НОВИЧКОВ БЕЗ СТРАХА!

### ❓ Вопросы, которые волнуют каждого новичка

**1️⃣ Что такое терминал простыми словами?**

**Аналогия с обычной жизнью:**
Представьте, что вы заказываете пиццу:

- **GUI (кнопки и меню)** = Тыкать пальцем в картинки на планшете официанта
- **Терминал (команды)** = Сказать официанту: "Пепперони, большая, тонкое тесто"

Терминал — это просто **разговор с компьютером на его языке**. Вместо кликов мышью вы пишете, что хотите. Компьютер понимает быстрее!

**Почему это лучше:**

- ⚡ **Быстрее:** "Открой папку проекты" vs 5 кликов мышью
- 🎯 **Точнее:** Компьютер делает РОВНО то, что вы сказали
- 🤖 **Повторяемо:** Одну команду можно выполнить 100 раз автоматически
- 💪 **Мощнее:** Доступны функции, которых НЕТ в обычных окнах

**Пример из жизни:**

```bash
# Вместо: Правая кнопка → Создать → Папка → Ввести название → Enter
# Просто напишите:
mkdir my-project

# Компьютер создал папку "my-project" за 0.1 секунды!
```

---

**2️⃣ Какие базовые команды нужно знать?**

**Думайте о терминале как о разговоре:**

| Вы хотите                 | Что говорите компьютеру | Команда           |
| ------------------------- | ----------------------- | ----------------- |
| "Где я нахожусь?"         | Print Working Directory | `pwd`             |
| "Что здесь лежит?"        | List                    | `ls`              |
| "Пойдем в другую комнату" | Change Directory        | `cd папка`        |
| "Создай новую коробку"    | Make Directory          | `mkdir название`  |
| "Создай пустой лист"      | Touch                   | `touch файл.txt`  |
| "Покажи содержимое листа" | Concatenate             | `cat файл.txt`    |
| "Скопируй это"            | Copy                    | `cp откуда куда`  |
| "Переименуй/перемести"    | Move                    | `mv старое новое` |
| "Удали это"               | Remove                  | `rm файл`         |

**Запомните:** Всего **5 команд** покрывают 80% ваших задач:

```bash
pwd     # Где я?
ls      # Что здесь?
cd      # Перейти туда
mkdir   # Создать папку
touch   # Создать файл
```

---

**3️⃣ Как не заблудиться в папках?**

**Терминал = лифт в многоэтажке:**

```bash
# Вы на 5 этаже (папка /home/user/projects)
pwd
# Показывает: /home/user/projects  ← это "адрес" где вы

# Посмотреть, что на этом этаже:
ls
# Показывает: project1  project2  photos

# Спуститься в project1:
cd project1

# Проверить адрес:
pwd
# Теперь: /home/user/projects/project1

# Подняться на этаж выше (вернуться назад):
cd ..

# Телепортироваться "домой":
cd ~
```

**Лайфхак:** Нажимайте **Tab** для автодополнения!

```bash
cd proj[Tab]  → компьютер допишет: cd projects/
```

---

**4️⃣ Как создавать и удалять файлы безопасно?**

**Создание — это как положить пустой лист на стол:**

```bash
# Создать один файл:
touch shopping-list.txt

# Создать несколько файлов:
touch notes.txt ideas.txt todo.txt

# Создать папку для файлов:
mkdir documents

# Создать вложенные папки (как матрешки):
mkdir -p work/projects/important
```

**Удаление — ОСТОРОЖНО, как с ножницами!**

```bash
# Удалить один файл:
rm old-file.txt

# Удалить папку:
rm -r old-folder/

# ⚠️ ОПАСНАЯ КОМАНДА (без подтверждения):
rm -rf folder/
# Это как сжечь документы — назад не вернешь!
```

**🛡️ Золотое правило безопасности:**

1. **Всегда проверяйте `pwd`** перед удалением (где вы находитесь)
2. **Используйте `ls`** перед удалением (что здесь лежит)
3. **Никогда не копируйте команды с `rm -rf` из интернета** бездумно!

---

**5️⃣ Что делать, если команда "зависла"?**

**Аналогия:** Программа зависла как загруженный браузер.

**Экстренные кнопки:**

```bash
Ctrl + C    # "СТОП!" — прервать команду
Ctrl + Z    # "ПАУЗА" — заморозить программу
Ctrl + D    # "ВЫХОД" — закрыть терминал
Ctrl + L    # "ОЧИСТИТЬ ЭКРАН" — убрать беспорядок
```

**Пример:**

```bash
# Запустили что-то долгое:
npm install

# Передумали — жмите:
Ctrl + C

# Терминал снова готов к командам!
```

**6️⃣ Как найти нужный файл в сотнях папок?**

**Аналогия:** Поиск носка в огромном шкафу.

**Команда `find` — ваш детектив:**

```bash
# Найти все файлы .txt:
find . -name "*.txt"

# Найти файлы, измененные сегодня:
find . -mtime -1

# Найти файлы больше 10MB:
find . -size +10M
```

**Команда `grep` — поиск текста внутри файлов:**

```bash
# Найти слово "password" во всех файлах:
grep -r "password" .

# Показать номера строк:
grep -n "TODO" script.js
```

**Реальный пример:**

```bash
# "Где я сохранил заметку про рецепт пиццы?"
grep -r "пицца" ~/Documents/

# Результат: ~/Documents/notes/recipes.txt:25: Рецепт пиццы Маргарита
```

- `pwd` - Показать текущую папку
- `ls` - Список файлов
- `ls -la` - Подробный список со скрытыми файлами
- `cd folder` - Перейти в папку
- `cd ..` - На уровень выше
- `cd ~` - В домашнюю папку
- `cd -` - В предыдущую папку

## 📁 Работа с файлами и папками
- `mkdir name` - Создать папку
- `mkdir -p path/to/folder` - Создать вложенные папки
- `touch file.txt` - Создать файл
- `cp file.txt copy.txt` - Копировать файл
- `cp -r folder/ copy/` - Копировать папку
- `mv old.txt new.txt` - Переименовать
- `mv file.txt folder/` - Переместить
- `rm file.txt` - Удалить файл
- `rm -r folder/` - Удалить папку

## 📖 Просмотр файлов
- `cat file.txt` - Показать весь файл
- `less file.txt` - Постраничный просмотр
- `head -n 10 file.txt` - Первые 10 строк
- `tail -n 10 file.txt` - Последние 10 строк
- `tail -f log.txt` - Следить за изменениями

## 🔍 Поиск
- `find . -name "*.txt"` - Найти все .txt файлы
- `grep "слово" file.txt` - Поиск текста в файле
- `grep -r "слово" .` - Рекурсивный поиск

## ⚡ Горячие клавиши
- `Ctrl + C` - Прервать команду
- `Ctrl + Z` - Приостановить
- `Ctrl + L` - Очистить экран
- `Ctrl + R` - Поиск по истории
- `Tab` - Автодополнение
- `↑/↓` - История команд

## 🎨 Полезные алиасы
- `alias ll='ls -lah'` - Подробный список
- `alias ..='cd ..'` - Быстро вверх
- `alias gs='git status'` - Git статус

## 🔧 Системные команды
- `echo "text"` - Вывести текст
- `which python` - Где находится программа
- `ps aux` - Список процессов
- `kill PID` - Завершить процесс

## 📝 Перенаправление
- `command > file.txt` - Записать вывод в файл
- `command >> file.txt` - Добавить в файл
- `command1 | command2` - Передать вывод

## 🚀 VibeCoding команды
- `claude` - Запустить Claude Code
- `git status` - Статус репозитория
- `npm install` - Установить зависимости
- `npm run dev` - Запустить dev сервер
