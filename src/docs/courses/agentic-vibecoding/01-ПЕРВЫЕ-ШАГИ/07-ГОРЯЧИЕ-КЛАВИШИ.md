### **📋 КОПИРОВАНИЕ И ВСТАВКА**

#### **Базовые комбинации:**

| Действие       | Windows/Linux | macOS             |
| -------------- | ------------- | ----------------- |
| **Копировать** | `Ctrl + C`    | `Cmd + C`         |
| **Вырезать**   | `Ctrl + X`    | `Cmd + X`         |
| **Вставить**   | `Ctrl + V`    | `Cmd + V`         |
| **Отменить**   | `Ctrl + Z`    | `Cmd + Z`         |
| **Вернуть**    | `Ctrl + Y`    | `Cmd + Shift + Z` |

#### **💡 Профи-советы:**

```
🎯 Копируй ВЕСЬ блок кода сразу, а не по строчке
🎯 Используй Ctrl+A для выделения всего
🎯 Ctrl+D для дублирования строки (в большинстве редакторов)
```

### **🔍 ВЫДЕЛЕНИЕ ТЕКСТА**

#### **Мышкой:**

- **Одинарный клик** — поставить курсор
- **Двойной клик** — выделить слово
- **Тройной клик** — выделить всю строку
- **Клик + перетаскивание** — выделить произвольный фрагмент

| Действие               | Windows/Linux         | macOS             |
| ---------------------- | --------------------- | ----------------- |

## 🎯 ПРАКТИЧЕСКИЕ СЦЕНАРИИ

### **📝 СЦЕНАРИЙ 1: Копируем код с GitHub**

**Обычный способ (медленно):**

1. Открыть GitHub → найти файл → прокрутить → выделить мышкой → копировать

**⚡ Профи-способ:**

1. `Ctrl + A` — выделить весь код
2. `Ctrl + C` — копировать
3. Перейти в редактор (`Alt + Tab`)
4. `Ctrl + V` — вставить
5. `Ctrl + Shift + P` → "Format Document" — отформатировать

### **🔧 СЦЕНАРИЙ 2: Быстрое редактирование**

**Задача:** Заменить все `console.log` на `console.error`

**⚡ Способ:**

1. `Ctrl + H` — открыть замену
2. Ввести `console.log` → `console.error`
3. `Alt + A` — заменить все
4. `Escape` — закрыть панель

### **🐛 СЦЕНАРИЙ 3: Отладка в браузере**

**⚡ Быстрая отладка:**

1. `F12` — открыть DevTools
2. `Ctrl + Shift + C` — инспектор элементов
3. Клик на элемент на странице
4. В консоли: изменить стили, проверить JavaScript

### **⚙️ КАСТОМНЫЕ ГОРЯЧИЕ КЛАВИШИ**

#### **В VS Code:**

1. `Ctrl + Shift + P` → "Preferences: Open Keyboard Shortcuts"
2. Найдите нужную команду
3. Назначьте удобную комбинацию

#### **Популярные кастомизации:**

```json
{
  "key": "ctrl+shift+d",
  "command": "editor.action.duplicateSelection"
},
{
  "key": "ctrl+shift+up",
  "command": "editor.action.copyLinesUpAction"
},
{
  "key": "ctrl+enter",
  "command": "workbench.action.terminal.new"
}
```

### **🖱️ Настройка мыши:**

- **Увеличить скорость** указателя
- **Настроить прокрутку** (быстрее для длинных файлов)
- **Дополнительные кнопки** для браузера (вперед/назад)

## ❓ ВОПРОСЫ PRODUCTIVITY SHORTCUTS ДЛЯ НОВИЧКОВ

### **1️⃣ Зачем вообще учить горячие клавиши?**

**Короткий ответ:** Скорость и здоровье.

**Развернутый:**

- **🚀 Скорость:** Горячие клавиши в 10-20 раз быстрее мыши
  - Мышью: перевести взгляд → найти курсор → прицелиться → кликнуть (2-3 сек)
  - Клавишами: нажать комбинацию (0.2 сек)
- **🧠 Фокус:** Руки остаются на клавиатуре → мозг в потоке
  - Не отвлекаетесь на поиск мыши
  - Меньше переключений внимания
  - Глубже погружение в код
- **💪 Здоровье:** Меньше движений = меньше усталости
  - Снижает риск туннельного синдрома
  - Меньше нагрузка на запястье
  - Лучше осанка (не тянешься к мыши)

**💡 Реальный пример:**

```
Задача: Скопировать 10 блоков кода из разных файлов

С мышью:
- Найти файл → кликнуть → выделить → копировать → переключиться
- 10 файлов × 15 секунд = 2.5 минуты

С клавишами:
- Ctrl+P (поиск файла) → Enter → Ctrl+A → Ctrl+C → Alt+Tab
- 10 файлов × 3 секунды = 30 секунд

ЭКОНОМИЯ: 2 минуты на простой задаче!
За день таких операций сотни → экономия ЧАСОВ

### **5️⃣ Как быстро запомнить горячие клавиши?**

#### **1. Muscle Memory (Мышечная память)**

**Принцип:** Руки запоминают быстрее мозга!

**Упражнение "10×10":**

```
Выберите 1 клавишу (например, Ctrl+D)
Повторите её 10 раз подряд
Делайте 10 подходов в течение дня

День 1: Ctrl+D (множественное выделение)
День 2: Alt+↑↓ (перемещение строк)
День 3: Ctrl+/ (комментарий)
...

Через неделю = 7 новых клавиш на автомате!
```

#### **2. Стикеры-шпаргалки**

**Где клеить:**

- На монитор (углы)
- На стол перед клавиатурой
- В Notion/Obsidian как quick reference

**Шаблон стикера:**

```
┌─────────────────────┐
│ DAILY SHORTCUTS     │
├─────────────────────┤
│ Ctrl+P → Файл       │
│ Ctrl+D → Выделить   │
│ Alt+↑  → Вверх      │
│ Ctrl+/ → Коммент    │
└─────────────────────┘
```

#### **3. Gamification (Челленджи)**

**"Неделя без мыши" — правила:**

```
День 1-2: Базовые операции (копировать/вставить)
День 3-4: Навигация по файлам (Ctrl+P, Ctrl+Tab)
День 5-6: Редактирование (множественные курсоры)

```

### **6️⃣ Какие ошибки делают новички при изучении shortcuts?**

```
❌ Неправильно:
"Сегодня выучу 50 комбинаций!"
Результат: через день забыли всё

✅ Правильно:
"Сегодня освою 3-5 самых частых"
Результат: через неделю 20+ клавиш на автомате
```

#### **Ошибка #2: Не практикуют регулярно**

```
❌ Неправильно:
Прочитал статью → забыл → вернулся к мыши

✅ Правильно:
Каждый день ЗАСТАВЛЯЮ себя использовать новые клавиши

```
❌ Неправильно:
"Мне неудобна стандартная комбинация, но так надо"

✅ Правильно:
Ctrl+Shift+P → "Preferences: Keyboard Shortcuts"
Настроил под свои руки → теперь удобно!
```

```
❌ Неправильно:
Дедлайн горит → хватаюсь за мышь → забываю клавиши

✅ Правильно:
Даже под давлением держусь клавиатуры
Через 2 недели это быстрее мыши!
```

#### **Ошибка #5: Игнорируют контекст использования**

```
❌ Неправильно:
Учат клавиши, которые никогда не используют

✅ Правильно:
Анализируют свою работу:
"Какие 10 действий делаю чаще всего?"
Учат ИМЕННО эти клавиши!
```
