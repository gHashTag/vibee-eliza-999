## 🧠 ТЕОРИЯ ПРОМПТИНГА 2025: НАУКА О ДИАЛОГЕ С AI

### 📐 **Математическая основа промптинга**

#### Формула эффективного промпта:

```
E = (C × S × I) / A

Где:
E - Эффективность промпта
C - Контекст (0-1)
S - Специфичность (0-1)
I - Инструкции (0-1)
A - Амбивалентность (1-∞)
```

#### Принцип информационной энтропии:

```
H(prompt) = -Σ p(xi) × log2(p(xi))

Чем ниже энтропия → тем точнее результат
Оптимальная энтропия: 2.5-3.5 бит
```

### 🔬 **Квантовая теория промптинга**

#### Принцип суперпозиции промптов:

```
|prompt⟩ = α|specific⟩ + β|abstract⟩

где |α|² + |β|² = 1
```

**Оптимальное соотношение:**

- 70% конкретики (α = 0.84)
- 30% абстракции (β = 0.55)

#### Коллапс волновой функции:

```
При наблюдении (генерации) промпт коллапсирует в:
- Детерминированный результат (температура < 0.3)
- Вероятностный результат (температура > 0.7)
```

### 🌊 **Теория потоковых промптов**

#### Модель "Река сознания":

```mermaid
graph LR
    A[Исток: Намерение] --> B[Русло: Контекст]
    B --> C[Пороги: Constraints]
    C --> D[Дельта: Результаты]
    D --> E[Океан: Интеграция]
```

#### Техника "Cascading Prompts":

```python
# Уровень 1: Абстрактная задача
prompt_1 = "Нужна система управления задачами"

# Уровень 2: Конкретизация
prompt_2 = f"{result_1} + Kanban доска с drag-n-drop"

# Уровень 3: Детализация

# Уровень 4: Оптимизация

```

## 🆘 РЕШЕНИЕ ПРОБЛЕМ

### ❓ Cursor не отвечает

1. Проверьте интернет соединение
2. Перезапустите Cursor
3. Очистите кэш: `Cmd/Ctrl + Shift + P` → "Clear Cache"
4. Проверьте статус серверов: status.cursor.com

### 🐌 Медленная работа

1. Уменьшите размер контекста (@file вместо @codebase)
2. Исключите node_modules из индексации
3. Закройте неиспользуемые файлы
4. Переключитесь на более быструю модель

### 🚫 Плохие предложения

1. Добавьте больше контекста в промпт
2. Используйте конкретные примеры
3. Укажите желаемый стиль кода
4. Попробуйте другую модель

**2. В чем разница между режимами Cmd+K и Cmd+I в Cursor?**

<details>
<summary>💡 Развернуть ответ</summary>

**Cmd+K (Manual Mode) — Точечное редактирование:**

```
✅ Работает с выделенным кодом
✅ Предпросмотр ВСЕХ изменений
✅ Принятие/отклонение по частям
✅ Максимальный контроль
✅ Быстрые правки

Пример:
Выделите функцию → Cmd+K → "Добавь error handling"
```

**Cmd+I (Agent Mode) — Автономный разработчик:**

```
✅ Создание/редактирование множества файлов
✅ Полная автономность
✅ Понимание контекста всего проекта
✅ Автоматическое применение изменений
✅ Комплексные задачи

Пример:
Cmd+I → "Создай систему авторизации с JWT, middleware, тестами"
```

**Когда использовать:**

- **Cmd+K**: Мелкие правки, рефакторинг, добавление фич
- **Cmd+I**: Новые модули, архитектурные изменения, большие фичи
</details>

**3. Какие основные режимы работы есть в Cursor и для чего каждый?**

<details>
<summary>💡 Развернуть ответ</summary>

**4 основных режима Cursor:**

**1️⃣ Agent Mode (Cmd+I)** — Автономный разработчик

```yaml
Для чего: Комплексные задачи, множество файлов
Автономность: Высокая
Пример: "Создай REST API с аутентификацией"
```

**2️⃣ Ask Mode (Cmd+L)** — AI-консультант

```yaml
Для чего: Объяснения, отладка, обучение
Автономность: Нет изменений кода
Пример: "Объясни как работает эта функция"
```

**3️⃣ Manual Mode (Cmd+K)** — Контролируемое редактирование

```yaml
Для чего: Точечные правки с предпросмотром
Автономность: Низкая (вы контролируете)
Пример: "Оптимизируй эту функцию"
```

**4️⃣ Background Mode (Cmd+E)** — Параллельная работа

```yaml
Для чего: Долгие задачи в фоне
Автономность: Высокая (не блокирует)
Пример: "Мигрируй проект на TypeScript"
```

**Матрица выбора:**
| Задача | Режим |
|--------|-------|
| Новый модуль | Agent (Cmd+I) |
| Вопрос по коду | Ask (Cmd+L) |
| Исправить баг | Manual (Cmd+K) |
| Рефакторинг большого проекта | Background (Cmd+E) |

</details>
