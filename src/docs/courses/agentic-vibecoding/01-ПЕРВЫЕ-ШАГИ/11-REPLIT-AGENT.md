## 🆘 Troubleshooting

### ❌ **Replit Agent не понимает задачу**

**Причина:** Слишком сложный или неточный промпт  
**Решение:**

```
❌ Плохо: "Сделай крутое приложение"
✅ Хорошо: "Создай веб-приложение для бронирования столиков в ресторане с календарем и уведомлениями"
```

### ❌ **Код не работает**

**Причина:** Ошибка в зависимостях или API  
**Решение:**

```
1. Скажи агенту: "Код не работает, исправь ошибку"
2. Покажи текст ошибки
3. Агент сам найдет и исправит проблему
```

### ❌ **Медленная работа**

**Причина:** Перегрузка серверов Replit  
**Решение:**

```
1. Попробуй через час
2. Используй Replit Pro (быстрее)
3. Создавай проекты по частям
```

### ❌ **Агент создает не то что нужно**

**Причина:** Нечеткое техническое задание  
**Решение:**

```
Используй структурированный промпт:
1. Что делает приложение (1 предложение)
2. Кто пользователи (целевая аудитория)
3. Основные функции (3-5 пунктов)
4. Технические требования (база данных, API)
5. Дизайн (стиль, цвета)
```
