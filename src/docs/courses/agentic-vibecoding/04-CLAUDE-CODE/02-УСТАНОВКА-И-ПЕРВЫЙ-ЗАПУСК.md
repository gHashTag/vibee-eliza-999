## 🔑 Настройка авторизации

Claude Code поддерживает 2 способа авторизации:

### **Способ 1: Claude Pro подписка (Рекомендуется)**

**Преимущества:**

- ✅ Выше лимиты использования
- ✅ Приоритетный доступ к новым моделям
- ✅ Быстрее ответы
- ✅ Поддержка artifacts

**Настройка:**

```bash
# Запустить Claude Code
claude

# При первом запуске откроется браузер
# Войдите в аккаунт claude.ai с Pro подпиской
```

### **Способ 2: Anthropic API ключ**

**Когда использовать:**

- Нет Claude Pro подписки
- Нужна автоматизация (headless режим)
- Работаете в организации с корпоративным API

**Настройка:**

1. **Получите API ключ:**

   - Зайдите на https://console.anthropic.com
   - Создайте новый API ключ
   - Скопируйте его (начинается с `sk-ant-`)

2. **Сохраните ключ:**

```bash
# Создайте файл .env в домашней папке
echo "ANTHROPIC_API_KEY=sk-ant-ваш-ключ-здесь" >> ~/.env

# Или установите переменную окружения
export ANTHROPIC_API_KEY=sk-ant-ваш-ключ-здесь
```

3. **Проверьте:**

```bash
claude "Привет, Claude!"
```

Если всё настроено правильно — Claude ответит вам.

## ⚙️ Конфигурация для вайбкодинга

### **Создайте файл настроек**

Claude Code использует файл `~/.claude/settings.json` для персональных настроек.

```bash
# Создайте папку конфигурации
mkdir -p ~/.claude

# Создайте файл настроек
cat > ~/.claude/settings.json << 'EOF'
{
  "model": "claude-sonnet-4.5",
  "outputStyle": "explanatory",
  "temperature": 0.7,
  "confirmBeforeExecute": true,
  "autoSave": true,
  "gitIntegration": true
}
EOF
```

### **Объяснение настроек:**

**`model`** — Модель Claude для использования

- `claude-sonnet-4.5` — Рекомендуется (быстрая + качественная)
- `claude-opus-4` — Самая умная (медленнее, дороже)
- `claude-haiku-4` — Самая быстрая (проще задачи)

**`outputStyle`** — Стиль ответов

- `explanatory` — Подробные объяснения (для обучения)
- `concise` — Краткие ответы (для профи)
- `technical` — Технические детали

**`temperature`** — Креативность (0-1)

- `0.3-0.5` — Предсказуемый код (production)
- `0.7-0.8` — Креативные решения (эксперименты)

**`confirmBeforeExecute`** — Спрашивать перед опасными операциями

- `true` — Безопаснее (рекомендуется)
- `false` — Автономнее (для опытных)

## 🎨 Настройка Output Style

Output Style контролирует как Claude объясняет свои действия.

### **Explanatory (Объяснительный) — Для обучения**

```json
{
  "outputStyle": "explanatory"
}
```

**Пример ответа:**

```
Создаю функцию для валидации email. Использую регулярное выражение
для проверки формата. Добавляю типы TypeScript для безопасности.

★ Insight: Регулярные выражения — мощный инструмент, но сложный.
Для production лучше использовать библиотеку типа validator.js
```

### **Concise (Краткий) — Для профи**

```json
{
  "outputStyle": "concise"
}
```

**Пример ответа:**

```
Created validateEmail() with regex pattern and TypeScript types.
```

### **Technical (Технический) — Для углубления**

```json
{
  "outputStyle": "technical"
}
```

**Пример ответа:**

```
Implemented RFC 5322 compliant email validation using:
- Regex pattern: /^[^\s@]+@[^\s@]+\.[^\s@]+$/
- TypeScript: (email: string) => boolean
- Test coverage: 95%
```

**💡 Совет для вайбкодера:** Начните с `explanatory` для обучения, потом переходите на `concise`.

## 🐛 Troubleshooting (Решение проблем)

### **Проблема 1: "Command not found: claude"**

**Решение:**

```bash
# Переустановите глобально
npm install -g @anthropic-ai/claude-code

# Проверьте PATH
echo $PATH | grep npm

# Если npm не в PATH, добавьте:
echo 'export PATH="$PATH:$(npm config get prefix)/bin"' >> ~/.bashrc
source ~/.bashrc
```

### **Проблема 2: "Authentication failed"**

**Решение:**

```bash
# Проверьте API ключ
echo $ANTHROPIC_API_KEY

# Или войдите через браузер
claude login
```

### **Проблема 3: "Context too large"**

**Решение:**

```bash
# Очистите контекст
/clear

# Или уменьшите размер проекта в настройках
{
  "memory": {
    "maxTokens": 100000
  }
}
```

### **Проблема 4: Claude медленно отвечает**

**Решение:**

```bash
# Переключитесь на более быструю модель
{
  "model": "claude-haiku-4"
}

# Или используйте краткий стиль
{
  "outputStyle": "concise"
}
```

### 🚀 Задание 3: Проектное (50-60+ минут)

**"Автоматизация установки для команды"**

**Цель:** Создать shell-скрипт для автоматической установки и настройки Claude Code для всей команды.

**Что нужно сделать:**

1. **Создайте скрипт установки** `install-claude.sh`:

```bash
#!/bin/bash
# Claude Code Team Setup Script
# Автоматическая установка и настройка для команды

set -e  # Остановка при ошибке

echo "🚀 Claude Code Team Setup"
echo "========================="

# Проверка Node.js
echo ""
echo "📋 Проверка зависимостей..."
if ! command -v node &> /dev/null; then
    echo "❌ Node.js не установлен"
    echo "Установите Node.js v18+ с https://nodejs.org"
    exit 1
fi

NODE_VERSION=$(node --version | cut -d'v' -f2 | cut -d'.' -f1)
if [ "$NODE_VERSION" -lt 18 ]; then
    echo "❌ Требуется Node.js v18+, установлено: v$NODE_VERSION"
    exit 1
fi

echo "✅ Node.js $(node --version) установлен"

# Установка Claude Code
echo ""
echo "📦 Установка Claude Code..."
npm install -g @anthropic-ai/claude-code

# Проверка установки
if ! command -v claude &> /dev/null; then
    echo "❌ Claude Code не установлен корректно"
    echo "Проверьте PATH: $PATH"
    exit 1
fi

echo "✅ Claude Code $(claude --version) установлен"

# Создание конфигурации
echo ""
echo "⚙️  Создание конфигурации..."

cat > ~/.claude/settings.json << 'EOF'

  }

EOF

echo "✅ Конфигурация создана: ~/.claude/settings.json"

# Создание тестового проекта
echo ""
echo "🧪 Создание тестового проекта..."
mkdir -p ~/claude-team-test
cd ~/claude-team-test

# Тест Claude
echo ""
echo "🔍 Проверка работы Claude..."
claude "Создай файл test.txt с текстом 'Setup successful!'" --non-interactive

if [ -f "test.txt" ]; then
    echo "✅ Тест пройден: $(cat test.txt)"
else
    echo "⚠️  Предупреждение: тест не прошёл"
fi

# Финальные инструкции

echo ""
```
