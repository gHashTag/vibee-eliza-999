# УРОВНИ И ПУТИ ОБУЧЕНИЯ

От новичка до эксперта за 5 уровней. Каждый уровень — новые навыки и проекты.

---

## Обзор уровней

```
УРОВЕНЬ 5: МАСТЕР (1000+ очков)
│ Сложные системы
│ Обучаешь других
▲

УРОВЕНЬ 4: ЭКСПЕРТ (600-1000 очков)
│ Несколько ботов вместе
│ Первые деньги
▲

УРОВЕНЬ 3: РАЗРАБОТЧИК (300-600 очков)

```

## Уровень 1: Новичок (0-100 очков)

**Цель:** Создать первого бота в Telegram

### Задание 1.1: Подготовка (20 очков)

- [ ] Установить Node.js 18+, VS Code, Git
- [ ] Создать аккаунт GitHub
- [ ] Получить токен от @BotFather

**Проверка:** `node -v`, `git --version`

### Задание 1.2: Первый бот (30 очков)

- [ ] Создать проект
- [ ] Установить Telegraf
- [ ] Бот отвечает на /start и /help
- [ ] Код на GitHub

### Задание 1.3: Кнопки и память (50 очков)

- [ ] Добавить кнопки
- [ ] Бот запоминает имя
- [ ] Работает круглосуточно (t.me/ваш_бот)

**Награда:** 🤖 Первый Бот

---

## Уровень 2: Практик (100-300 очков)

**Цель:** Подключить искусственный интеллект

### Задание 2.1: Первый ИИ (25 очков)

- [ ] Получить ключ для ИИ (например OpenAI)
- [ ] Команда /ai для вопросов
- [ ] Обработать ошибки

**Проверка:** `/ai Что такое код?` → умный ответ

### Задание 2.2: Умный диалог (40 очков)

- [ ] Бот помнит 5-10 сообщений
- [ ] Настроить характер
- [ ] Команда /reset

**Проверка:** Бот понимает контекст разговора

### Задание 2.3: Продвинутые функции (60 очков)

- [ ] Ответы списками
- [ ] Анализ настроения
- [ ] Создание планов
- [ ] Описание фото

### Задание 2.4: Ответы по документам (75 очков)

- [ ] Система поиска
- [ ] Загрузка документов
- [ ] Поиск по смыслу
- [ ] Ответы из документов

**Награда:** 🧙 Волшебник ИИ

---

## Уровень 3: Разработчик (300-600 очков)

**Цель:** Бот с памятью и постоянной работой

### Задание 3.1: Подключаем интернет (50 очков)

- [ ] Поиск в интернете
- [ ] Погода и курсы валют
- [ ] Сохранение ответов

### Задание 3.2: Долговременная память (75 очков)

- [ ] База данных
- [ ] Сохранение пользователей
- [ ] История разговоров
- [ ] Заметки и напоминания

**Проверка:** `/note Купить хлеб` → перезапуск → заметка на месте

### Задание 3.3: Работа 24/7 (100 очков)

- [ ] Упаковать в контейнер
- [ ] Логирование
- [ ] Отслеживание ошибок

### Задание 3.4: Автоматические задачи (75 очков)

- [ ] Очередь задач
- [ ] Задачи по расписанию
- [ ] Уведомления
- [ ] Копии базы

**Награда:** 💾 Мастер Данных

## Уровень 4: Эксперт (600-1000 очков)

**Цель:** Команда ботов и первые деньги

### Задание 4.1: Команда ботов (100 очков)

- [ ] 3+ бота работают вместе
- [ ] Главный управляет остальными
- [ ] Общая память
- [ ] Передача задач

### Задание 4.2: Полезный продукт (75 очков)

- [ ] Выбрать аудиторию
- [ ] Решить проблему
- [ ] Создать рабочую версию
- [ ] Страница описания

### Задание 4.3: Первые деньги (125 очков)

- [ ] Приём платежей
- [ ] Подписки
- [ ] 3+ платящих клиента
- [ ] Поддержка пользователей

### Задание 4.4: Много пользователей (100 очков)

- [ ] Распределение нагрузки
- [ ] Защита от перегрузки
- [ ] Контроль расходов

**Награда:** 🚀 Предприниматель

## Уровень 5: Мастер (1000+ очков)

**Цель:** Создавай и обучай

**Свободный уровень:**

- Свои инструменты
- Обучение других
- Открытые проекты
- Выступления
- Статьи и курсы

## Три пути обучения

### 🐢 Новичок (8 недель)

Никогда не программировал → 1-2 часа/день

- Недели 1-2: Уровень 1
- Недели 3-4: Уровень 2
- Недели 5-6: Уровень 3
- Недели 7-8: Уровень 4

### 🚶 Практик (6 недель)

Знаю основы → 2-3 часа/день

- Неделя 1: Уровень 1
- Недели 2-3: Уровень 2
- Недели 4-5: Уровень 3
- Неделя 6: Уровень 4

### 🏃 Профи (4 недели)

Опытный разработчик → 3-4 часа/день

- Дни 1-2: Уровень 1
- Дни 3-7: Уровень 2
- Недели 2-3: Уровень 3
- Неделя 4: Уровень 4

## Как перейти на следующий уровень

**Требования:**

1. Закончить все задания уровня
2. Набрать нужное количество очков
3. Ответить на вопросы самопроверки
4. Сделать итоговый проект

**Вопросы самопроверки:**

- Чему я научился?
- Что было сложно?
- Что я создал?
- Готов ли к следующему уровню?

## Настрой под себя

**Можешь ускориться:**

- Пропустить задание если умеешь (покажи что умеешь)
- Делать несколько заданий сразу

**Можешь замедлиться:**

- Разбить задание на части
- Повторять пока не поймёшь

**Можешь изменить:**

- Больше времени на интересное
- Меньше на то что знаешь
- Свои дополнительные проекты
