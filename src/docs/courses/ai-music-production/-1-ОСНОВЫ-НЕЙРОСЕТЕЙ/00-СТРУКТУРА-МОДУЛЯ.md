### 02. Как работают нейросети: Просто о сложном

**Длительность:** 45 минут

**Что узнаете:**

- Принцип работы: Нейроны → Слои → Обучение
- Текст → Текст (GPT, Claude) - как работает ChatGPT
- Текст → Изображение (FLUX, Stable Diffusion) - как создаются обложки
- Изображение → Видео (Kling, Wan) - как оживают картинки
- Текст → Видео (Sora, Minimax) - прямая генерация клипов

**Визуальная схема:**

```
ТЕКСТ (промпт)
    ↓
[НЕЙРОСЕТЬ: 1 млрд параметров]
    ↓
ИЗОБРАЖЕНИЕ (1024x1024px)
    ↓
[НЕЙРОСЕТЬ: video diffusion]
    ↓
ВИДЕО (4-10 сек, 1080p)
```

**Аналогия для новичков:**

- Нейросеть = Художник, который видел 1 млрд картинок
- Промпт = Техническое задание художнику
- Модель = Стиль рисования (реализм vs аниме vs киберпанк)

### 04. Терминология: Говорим на языке AI

**Длительность:** 30 минут

#### 📝 Промпт (Prompt)

**Что это:** Текстовое описание для нейросети

**Примеры:**

```
❌ Плохой промпт: "красивая картинка"
✅ Хороший промпт: "cyberpunk city at night, neon signs,
   rain on streets, cinematic lighting, 8K, photorealistic"
```

#### 🎯 Токен (Token)

**Что это:** Единица текста (~0.75 слова английского, ~0.5 русского)

**Пример:**

```
Текст: "Привет мир" = ~4 токена
Текст: "Hello world" = ~2 токена
```

**Почему важно:** API многих сервисов считают цену по токенам

#### 🤖 Модель (Model)

**Что это:** Обученная нейросеть для конкретной задачи

**Типы:**

- **Текст → Текст:** GPT-4, Claude 4, Gemini 2.0
- **Текст → Изображение:** FLUX, DALL-E 3, Midjourney
- **Изображение → Видео:** Kling, Wan-2.1
- **Текст → Видео:** Sora 2, Minimax, Hunyuan
- **Аудио:** ElevenLabs (голос), Suno (музыка)

#### 🎨 Стиль (Style)

**Что это:** Характер генерации

**Примеры:**

- Photorealistic (фотореализм)
- Anime (аниме)
- Cyberpunk (киберпанк)
- Watercolor (акварель)
- Cinematic (кинематографичный)

#### 🔧 API (Application Programming Interface)

**Что это:** Способ автоматического доступа к нейросети

**Процесс:**

```
1. Регистрация на сайте
2. Получение API ключа (секретный пароль)
3. Отправка запроса через код/Postman
4. Получение результата в JSON
```

**В боте:** Весь API интегрирован под капотом, вы просто жмете кнопку!

#### 🎚️ Fine-tuning

**Что это:** Дообучение модели на своих данных

**Пример:**

- Базовая модель FLUX знает "женщина"
- Fine-tuned модель знает "Ваш артист Neon Phoenix"
- Результат: Генерирует именно вашего персонажа

#### 📐 Разрешение (Resolution)

**Форматы для музыки:**

- **Обложки:** 3000x3000px (Spotify требует минимум 640x640)
- **YouTube превью:** 1280x720px (720p)
- **Instagram Reels:** 1080x1920px (вертикальное 9:16)
- **TikTok:** 1080x1920px (вертикальное 9:16)
