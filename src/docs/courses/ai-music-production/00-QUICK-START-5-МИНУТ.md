## 📱 ШАГ 1: Открой бота (30 секунд)

**Что делаем:**

1. Открой Telegram
2. Найди бота **@neurotester_bot** (или твоего личного бота)
3. Нажми `/start` если это первый запуск

**Что увидишь:**
Главное меню с кнопками функций бота.

> 💡 **Подсказка:** Если не видишь меню — нажми на иконку клавиатуры внизу экрана (слева от поля ввода).

_[📸 Screenshot placeholder: Главное меню бота с кнопками]_

## 🎨 ШАГ 2: Нажми кнопку "ИИ Фотошоп" (30 секунд)

**Что делаем:**

1. В главном меню найди кнопку **🎨 ИИ Фотошоп**
2. Просто нажми на неё

**Что увидишь:**
Бот попросит тебя описать, что ты хочешь создать.

> 🎨 **Fun fact:** Эта кнопка использует FLUX Kontext — одну из самых мощных нейросетей для создания изображений в 2025 году!

_[📸 Screenshot placeholder: Кнопка "ИИ Фотошоп" в меню]_

## ✍️ ШАГ 3: Скопируй и отправь промпт (1 минута)

**Что делаем:**
Скопируй этот текст и отправь боту:

```
Lo-Fi hip-hop album cover, cozy bedroom setup,
vinyl records on wooden desk, warm sunset light
through window, retro aesthetic, soft colors,
peaceful vibes, minimalist design
```

**Или на русском:**

```
Обложка Lo-Fi хип-хоп альбома, уютная комната с винилами,
теплый закатный свет из окна, ретро эстетика,
мягкие цвета, спокойная атмосфера
```

**Что это значит:**

- **Lo-Fi hip-hop** = стиль музыки (спокойный бит для учебы/работы)
- **Cozy bedroom setup** = уютная комната (популярный визуал для Lo-Fi)
- **Warm sunset light** = теплый свет заката (создает настроение)

> 💡 **Подсказка:** Промпт — это описание того, что ты хочешь увидеть. Чем подробнее описание, тем точнее результат!

_[📸 Screenshot placeholder: Отправленный промпт в чате]_

---

## ⏳ ШАГ 4: Жди результат (2 минуты)

**Что делаем:**
Просто жди! Нейросеть генерирует твою обложку.

**Что происходит прямо сейчас:**

1. Твой промпт отправляется на сервер
2. FLUX Kontext анализирует описание
3. Нейросеть создает уникальное изображение пиксель за пикселем
4. Результат отправляется обратно в Telegram

**Сколько ждать:**
Обычно 30-90 секунд. Время зависит от загрузки сервера.

> ☕ **Используй это время:** Подумай о названии трека или артиста. Например: "Sunset Beats" или "Midnight Study".

_[📸 Screenshot placeholder: Индикатор генерации / прогресс-бар]_

## 🎉 ШАГ 5: Твоя первая обложка готова! (1 минута)

**ТЫ СДЕЛАЛ ЭТО!** 🏆

Теперь у тебя есть:

- ✅ Профессиональная обложка для трека
- ✅ Опыт работы с AI генерацией
- ✅ Понимание, как описывать промпты

**Что можешь сделать с обложкой:**

1. **Скачать:** Нажми на изображение → Сохранить
2. **Улучшить качество:** Используй кнопку **⬆️ Увеличить качество фото**
3. **Создать еще:** Измени промпт и попробуй снова!

**Примеры модификаций промпта:**

```
Попробуй изменить:
- "sunset light" → "neon lights" (неоновый свет)
- "cozy bedroom" → "rooftop terrace" (крыша здания)
- "soft colors" → "vibrant purple and pink" (яркие цвета)
```

> 🎨 **Креативный челлендж:** Создай 3 варианта обложки для одного трека, меняя только цвета или локацию!
