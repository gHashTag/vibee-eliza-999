# 💫 Регистрация и подписка: Начало работы с ботом

## 🚀 За 5 минут ты будешь готов создавать

Никаких сложных регистраций, верификаций, анкет. Telegram уже знает, кто ты. Боту достаточно одного сообщения.

**Простота — это главное преимущество.**

---

## 📱 Шаг 1: Запуск бота

### Как найти бота?

#### Вариант 1: Прямая ссылка

```
https://t.me/YourMusicProductionBot
```

Просто открой ссылку → бот запустится автоматически.

#### Вариант 2: Поиск в Telegram

1. Открой Telegram
2. В поиске введи `@YourMusicProductionBot`
3. Нажми на бота в результатах
4. Нажми **START** или **ЗАПУСТИТЬ**

### Что происходит при первом запуске?

1. Бот приветствует тебя
2. Автоматически создает твой профиль
3. Начисляет **100 стартовых звезд** 🎁
4. Показывает главное меню с кнопками

**Это всё. Ты уже зарегистрирован.**

---

## 💰 Шаг 2: Проверка баланса

Первое, что нужно сделать — проверить свой баланс звезд.

### Нажми кнопку **💰 Баланс**

Увидишь:

```
🌟 Ваш баланс: 100 звезд

📊 Статистика:
- Создано изображений: 0
- Создано видео: 0
- Всего потрачено: 0 звезд

💳 История пополнений:
- 20.01.2025: +100 звезд (стартовый бонус)
```

### Что можно сделать на 100 звезд?

**Бесплатные стартовые 100 звезд** позволяют попробовать:

- **10 изображений** в ИИ Фотошоп (по 10 звезд)
- **2 коротких видео** из текста (по 50 звезд)
- **1 AI Reels** видео (30-50 звезд)
- **3-5 текстов в голос** (по 10-30 звезд)

Этого достаточно, чтобы **понять, как работает бот** и создать первые работы.

## 💎 Шаг 3: Пополнение баланса звездами

Когда стартовые 100 звезд закончатся (а они закончатся быстро, потому что ты войдешь в кураж), нужно пополнить баланс.

### Нажми кнопку **💎 Пополнить баланс**

Увидишь меню пакетов:

```
💎 Выберите пакет звезд:

🌟 Старт: 1000 звезд — $10
   (10+ изображений + 5 видео)

⭐ Базовый: 5000 звезд — $45 (-10%)
   (50 изображений + 25 видео)

✨ Профи: 10000 звезд — $80 (-20%)
   (100 изображений + 50 видео)

💫 Премиум: 50000 звезд — $350 (-30%)
   (500 изображений + 250 видео)

🚀 Агентство: 100000 звезд — $600 (-40%)
   (1000+ изображений + 500+ видео)
```

### Как выбрать пакет?

**Новичок (учишься)**:

- Пакет **Старт (1000 звезд)** — $10
- Хватит на 1-2 недели экспериментов
- Создашь портфолио из 10-15 работ

**Любитель (делаешь для себя)**:

- Пакет **Базовый (5000 звезд)** — $45
- Хватит на месяц активного использования
- 20-30 готовых работ

**Профессионал (работаешь с клиентами)**:

- Пакет **Профи (10000 звезд)** — $80
- Хватит на 2-3 недели постоянной работы
- 50-80 клиентских проектов

**Агентство (массовое производство)**:

- Пакет **Премиум (50000)** или **Агентство (100000)** — $350-600
- Хватит на месяц интенсивной работы
- 200-500 проектов для клиентов

### Рекомендация для курса

**Купи пакет Базовый (5000 звезд) сразу.**

Почему?

- За 30 дней курса ты создашь **50-100 работ**
- Это требует **3000-7000 звезд**
- Пакет Старт (1000) закончится за неделю
- Экономия **-10%** на Базовом пакете

### Telegram Stars (рекомендуется)

- Встроенная валюта Telegram
- Оплата через Google Pay / Apple Pay / карты
- Звезды приходят **мгновенно**
- Комиссия минимальная

**Как оплатить:**

1. Выбери пакет
2. Нажми "Оплатить через Telegram Stars"
3. Подтверди оплату
4. Звезды приходят сразу на баланс

### Банковская карта (прямая оплата)

- Visa, Mastercard, МИР
- Звезды приходят в течение **1-5 минут**
- Возможна оплата из любой страны

### Криптовалюта (для продвинутых)

- BTC, ETH, USDT
- Анонимность
- Подтверждение 10-30 минут

### Другие способы

- PayPal (для США/Европы)
- ЮMoney (для России)
- Payoneer (для фрилансеров)

## ⚙️ Управление подпиской

### Как оформить?

1. Нажми **💫 Оформить подписку**
2. Выбери тариф
3. Оплати через Telegram Stars / карту
4. Подписка активируется мгновенно

### Как отменить?

1. Нажми **💫 Оформить подписку**
2. Увидишь кнопку **"Отменить подписку"**
3. Подтверди отмену
4. Подписка останется активной до конца оплаченного периода

**Нет скрытых платежей. Нет автопродления без предупреждения.**

### Можно ли вернуть деньги?

- **Первые 3 дня** — да, полный возврат (если не использовал функции активно)
- **После 3 дней** — частичный возврат пропорционально неиспользованному времени
- **Звезды** — не возвращаются (можно использовать позже)

## 💬 Частые вопросы

### Что если у меня закончились звезды в процессе генерации?

Генерация остановится. Пополни баланс и запусти снова. Потраченные звезды не спишутся повторно.

### Можно ли использовать подписку на нескольких устройствах?

Да, подписка привязана к Telegram аккаунту, а не устройству.

### Сгорают ли звезды?

Нет, звезды хранятся на балансе без ограничения по времени.

### Можно ли перейти с подписки на звезды и обратно?

Да, в любой момент. Отмени подписку или оформи заново.

### Что дешевле: звезды или подписка?

Зависит от интенсивности использования. Смотри таблицу сравнения выше.

### Можно ли подарить подписку/звезды другу?

Да, напиши в поддержку — выпустим подарочный код.
