# Библиотека Стилей и Промптов для Музыкальных Обложек

## 🎯 Как Использовать Эту Библиотеку

Эта библиотека — твоя шпаргалка для создания обложек в любом жанре. Просто:

1. **Найди свой жанр** в списке ниже
2. **Скопируй промпт** (или адаптируй под свой трек)
3. **Вставь в 🎨 ИИ Фотошоп** → FLUX Kontext Pro
4. **Генерируй обложку** и наслаждайся результатом!

**Формат каждого раздела:**

- 🎵 **Жанр**
- 🎨 **Визуальный стиль**
- 🎨 **Цветовая палитра**
- 📝 **3-5 готовых промптов**
- 🔧 **Ключевые слова для модификации**

## 🔧 Универсальные Модификаторы

### Как Адаптировать Любой Промпт

**Сделать Темнее:**

```
+ "dark and moody, low key lighting, deep shadows"
```

**Сделать Ярче:**

```
+ "vibrant and colorful, well-lit, high energy"
```

**Добавить Винтаж:**

```
+ "vintage aesthetic, analog film look, retro style, 1970s/1980s"
```

**Сделать Минималистичнее:**

```
+ "minimalist, clean, simple composition, negative space"
```

**Добавить Футуризм:**

```
+ "futuristic, sci-fi aesthetic, neon lights, cyberpunk elements"
```

**Сделать Кинематографичнее:**

```
+ "cinematic composition, dramatic lighting, film photography style"
```

## 🎯 Практическое Задание

**Задача:** Создай 5 обложек в разных жанрах, используя промпты из библиотеки.

**Жанры для практики:**

1. Hip-Hop (используй любой промпт из раздела Hip-Hop)
2. Electronic (из раздела Electronic)
3. Lo-Fi (из раздела Lo-Fi)
4. Pop (из раздела Pop)
5. Jazz (из раздела Jazz)

**Цель:**

- Понять, как жанр влияет на визуал
- Научиться адаптировать промпты под свой стиль
- Создать портфолио обложек

---

## 📌 Ключевые Выводы

1. **Каждый жанр имеет визуальный язык** — изучи его перед созданием
2. **Промпты — это шаблоны** — адаптируй их под свой трек
3. **Цвет = 60% успеха обложки** — выбирай палитру по жанру
4. **Настроение важнее деталей** — фокусируйся на атмосфере
5. **Сохраняй удачные промпты** — они работают как база для будущих треков

💡 **Pro Tip:** Создай свой личный "промпт-банк" — файл с промптами, которые сработали для твоих треков. Это сэкономит часы времени в будущем!
