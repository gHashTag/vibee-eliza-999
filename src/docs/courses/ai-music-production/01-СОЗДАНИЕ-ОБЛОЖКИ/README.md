## ❓ FAQ

### Q: Сколько звезд нужно на весь модуль?

**A:** Минимум 33⭐ для практики, 55⭐ для полного EP-проекта.

### Q: Можно ли использовать FLUX без upscaling?

**A:** Для соцсетей — да. Для дистрибуции (Spotify/Apple Music) — нет, нужен upscaling до 3000x3000px.

### Q: Что если мне не нравится результат генерации?

**A:** Измени промпт и генерируй заново. Сохраняй удачные промпты для будущих треков.

### Q: Нужно ли мне знать Photoshop?

**A:** Нет! Все делается через бота. Photoshop нужен только для опциональной пост-обработки (текст, цветокоррекция).

### Q: Какая модель upscaling лучше?

**A:** **Real-ESRGAN 4x (2⭐)** — оптимальный баланс качества и цены.
