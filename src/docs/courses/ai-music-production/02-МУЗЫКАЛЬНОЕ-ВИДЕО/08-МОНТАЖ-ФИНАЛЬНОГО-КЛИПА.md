## 🎬 Полный Workflow монтажа

### ШАГ 1: Импорт материалов

**В CapCut:**

```
1. Создайте новый проект:
   - Название: "My Music Video"
   - Разрешение: 1920×1080 (16:9)
   - Framerate: 30 fps

2. Импортируйте все файлы:
   Media → Import
   - Выберите папку 01_RAW_FOOTAGE
   - Импортируйте рекурсивно все клипы
   - Импортируйте 02_AUDIO/full_track.mp3

3. Организуйте в бины (папки):
   - Создайте бины: Text2Video, Image2Video, Lipsync, Morphing
   - Распределите клипы по категориям
```

**В DaVinci Resolve:**

```
1. Создайте проект:
   File → New Project

2. Настройте Project Settings (Shift+9):
   Timeline Format: 1920×1080 HD
   Timeline Framerate: 30 fps
   Playback Framerate: 30

3. Импортируйте медиа:
   Media Pool → Import Media
   - Выберите все файлы
   - Создайте Smart Bins для организации
```

```
TIMELINE MARKERS:

0:45 - [CHORUS 1] First chorus
1:15 - [VERSE 2] Second verse

В CapCut:

В DaVinci:
- Нажмите M на timeline
- Shift+M для редактирования маркера
```

### ШАГ 3: Черновая сборка (Rough Cut)

**Расставьте клипы по структуре:**

```
INTRO [0:00-0:15]:
- Clip 1: Fade in от черного (3 сек)
- Clip 2: Establishing shot (5 сек)
- Clip 3: Title card с названием трека (3 сек)
- Clip 4: Переход к первому куплету (4 сек)

VERSE 1 [0:15-0:45]:
- Clip 5-8: 4 клипа по 7-8 секунд
- Используйте текст-видео или image-to-video
- Медленные движения камеры

CHORUS 1 [0:45-1:15]: ← ЭНЕРГИЯ!
- Clip 9: Infinity Морфинг (30 секунд) ← ГЛАВНЫЙ ЭЛЕМЕНТ!
- ИЛИ серия быстрых клипов (6-8 клипов по 4-5 сек)

VERSE 2 [1:15-1:45]:
- Clip 10-13: Lipsync артиста (если есть вокал)
- Или продолжение визуальной истории

CHORUS 2 [1:45-2:15]:
- Clip 14: Повтор лучших моментов
- Или новый Infinity Морфинг
- Добавить эффекты

BRIDGE [2:15-2:45]:
- Clip 15-16: Смена настроения
- Другой визуальный стиль
- Подготовка к кульминации

OUTRO [2:45-3:00]:
- Clip 17-18: Затухание
- Credits (имя артиста, название трека)
- Fade to black
```

**Техника расстановки:**

```
1. НЕ обрезайте клипы сразу точно
2. Положите все клипы с запасом
3. Просмотрите всю timeline под музыку
4. Отметьте места, где нужны правки
5. ПОТОМ начинайте точную обрезку
```

### ШАГ 4: Точная синхронизация (Fine Cut)

**Синхронизация с битами:**

```
ПРАВИЛО 4-Х БИТОВ:
Большинство переходов должны быть на каждом 4-м бите

Как найти биты:
1. В Audacity откройте трек
2. Analyze → Beat Finder
3. BPM: 120 (пример)
4. Каждый 4-й бит = (60 ÷ 120) × 4 = 2 секунды

ПРИМЕНЕНИЕ:
Каждые 2 секунды - потенциальная точка перехода!

В видеоредакторе:
- Включите метроном (если есть)
- Или используйте grid: Timeline → Snapping → 2 seconds
- Привязывайте cuts к сетке
```

**Типы cuts:**

```
1. HARD CUT (резкий):
   - На сильный бит
   - Смена сцены
   - Энергичные моменты

   Применение: [Clip A][Clip B]
   Нет перехода, мгновенная смена

2. CROSS DISSOLVE (растворение):
   - Плавный переход
   - Смена времени
   - Романтичные моменты

   Применение: [Clip A]~~[Transition]~~[Clip B]
   Длительность: 0.5-1 секунда

3. FADE TO BLACK:
   - Конец секции
   - Переход в outro

   Применение: [Clip]→[Black]
   Длительность: 1-2 секунды

4. WHIP PAN (быстрая панорама):
   - Быстрая смена
   - Энергичные моменты
   - EDM/Hip Hop

   В CapCut: Effects → Transitions → Whip
```

### ШАГ 5: Добавление эффектов

**Базовые эффекты в CapCut:**

```
1. SPEED RAMPING (изменение скорости):

   Как сделать:
   - Выберите клип
   - Speed → Curve
   - Создайте точки:
     [Normal speed]→[Slow motion]→[Normal speed]

   Применение:
   - На кульминации (замедлить момент)
   - Drop в EDM (slow → fast)
   - Эмоциональные моменты

2. ZOOM IN/OUT:

   Как сделать:
   - Выберите клип
   - Effects → Basic → Zoom
   - Keyframe start: Scale 100%
   - Keyframe end: Scale 120%

   Применение:
   - Нарастание напряжения
   - Привлечение внимания

3. GLITCH EFFECTS:

   Как сделать:
   - Effects → Video Effects → Glitch
   - Примените на beat drops

   Применение:
   - Киберпанк стиль
   - Технические сбои
   - Переходы

4. CHROMATIC ABERRATION:

   Как сделать:
   - Effects → Camera Effects → Chromatic Aberration

   Применение:
   - Аналоговый, vintage вид
   - Dreamy эффект

5. VIGNETTE:

   Как сделать:
   - Effects → Basic → Vignette
   - Intensity: 20-40%

   Применение:
   - Фокус на центре кадра
   - Кинематографический вид
```

**Продвинутые эффекты в DaVinci Resolve:**

```
1. COLOR GRADING (будет отдельно в Шаге 6)

2. MOTION BLUR:
   Fusion → Motion Blur
   - Shutter Angle: 180°

   Применение:
   - Реалистичные движения
   - Speed ramping

3. PARTICLE EFFECTS:
   Fusion → Particle Emitter

   Применение:
   - Дым, искры
   - Магические эффекты

4. SCREEN REPLACEMENT:
   Fusion → Planar Tracker

   Применение:
   - Замена экранов телефонов
   - Билборды в сцене
```

### ШАГ 6: Цветокоррекция (Color Grading)

**В CapCut (базовая):**

```
1. АВТОКОРРЕКЦИЯ:
   Adjustments → Auto Adjust
   - Быстрый способ для начала

2. РУЧНАЯ НАСТРОЙКА:

   Brightness: 0 → +10 (чуть светлее)
   Contrast: +15 (больше контраста)
   Saturation: +20 (ярче цвета)
   Temperature: Зависит от mood:
     - Холодный (-10): Киберпанк, ночь
     - Теплый (+10): Романтика, закат

   Vignette: 20-30% (темнее по краям)
   Sharpen: +10 (четкость)

3. ПРЕСЕТЫ:
   Filters → выберите стиль:
   - "Cinematic" для кино-вида
   - "Vintage" для ретро
   - "Neon" для киберпанка

4. LUT (Look-Up Table):
   Adjustments → LUT
   - Скачайте бесплатные LUTs онлайн
   - Примените для профессионального вида
```

**В DaVinci Resolve (профессиональная):**

```
WORKFLOW COLOR GRADING:

1. ПЕРЕЙДИТЕ В COLOR PAGE:
   Нажмите на иконку Color внизу

2. PRIMARY CORRECTION:

   Lift (Тени):
   - Поднимите немного для "milky" look
   - Или опустите для контраста

   Gamma (Средние тона):
   - Основная яркость
   - Настройте по taste

   Gain (Света):
   - Подчеркните блики
   - Не переборщите (clipping)

   Saturation:
   - Немного увеличьте (+10-20%)

3. SECONDARY CORRECTION (выборочная):

   Qualifier:
   - Выделите цвет (например, небо)
   - Настройте ТОЛЬКО этот цвет

   Пример:
   - Выделить все синее (небо, вода)
   - Увеличить saturation +30%
   - Результат: яркое небо, остальное как было

4. ЦВЕТОВАЯ ПАЛИТРА:

   Киберпанк:
   - Shadows: Cyan/Blue tint
   - Highlights: Pink/Magenta tint
   - Saturation: High (+30-40%)

   Cinematic:
   - Shadows: Slightly desaturated
   - Highlights: Warm tint
   - Contrast: High

   Vintage:
   - Overall: Yellow/Sepia tint
   - Grain: Add film grain
   - Vignette: Heavy

5. КОПИРОВАНИЕ GRADE НА ВСЕ КЛИПЫ:

   - Настройте первый клип
   - Правый клик → Copy Grade
   - Выделите все клипы
   - Правый клик → Paste Grade

   Результат: Единый стиль на всем видео!
```

**Референсы для цветокоррекции:**

```
ИЗУЧИТЕ:
- Blade Runner 2049 (Киберпанк)
- La La Land (Яркие, saturated цвета)
- Drive (Neon nights)
- The Revenant (Естественный, холодный)

Найдите кадр из референса
Попытайтесь повторить grade
Примените к своему клипу
```

### ШАГ 8: Аудио микс

**Уровни громкости:**

```
ПРАВИЛЬНЫЕ УРОВНИ:

Music Track: -3 dB (оставьте headroom)
Sound Effects: -12 до -6 dB (не перекрывают музыку)
Voice Over (если есть): -6 dB (слышен поверх музыки)

В CapCut:
- Выберите клип
- Volume → Adjust
- Используйте Volume Envelope для плавных изменений

FADE IN/OUT:
Start: Fade in (0.5-1 сек)
End: Fade out (2-3 сек)
```

**EQ и компрессия (DaVinci Resolve):**

```
FAIRLIGHT PAGE:

1. EQ (Эквализация):
   Effects → EQ
   - Low Cut: 20 Hz (убрать rumble)
   - Boost: 2-4 kHz (clarity)
   - High Shelf: +2 dB at 10 kHz (air)

2. Compressor:
   Effects → Compressor
   - Threshold: -12 dB
   - Ratio: 3:1
   - Attack: 10 ms
   - Release: 100 ms

   Результат: Более ровная громкость

3. Limiter (на мастер):
   Master Track → Limiter
   - Ceiling: -1 dB (избежать clipping)
   - Release: Fast
```

**Синхронизация SFX (звуковых эффектов):**

```
ДОБАВИТЬ ЭФФЕКТЫ:

Whoosh (свист):
- На быстрых переходах
- На whip pans
- Volume: -10 dB

Impact (удар):
- На hard cuts
- На beat drops
- Volume: -8 dB

Glitch (сбой):
- На glitch эффектах
- На технических моментах
- Volume: -12 dB

ИСТОЧНИКИ SFX:
- Freesound.org (бесплатно)
- Epidemic Sound (подписка)
- Artlist (подписка)
- Splice (отдельные файлы)
```

### ШАГ 9: Финальная проверка

**Чеклист перед экспортом:**

```
ВИЗУАЛ:
□ Все клипы на месте, нет пропусков
□ Переходы плавные и синхронизированы
□ Цветокоррекция применена ко всем клипам
□ Текст разборчив на всех устройствах
□ Нет артефактов (glitches, если не намеренные)
□ Aspect ratio правильный (16:9 или 9:16)

АУДИО:
□ Музыка не клипится (не превышает 0 dB)
□ Fade in/out на месте
□ Sound effects синхронизированы
□ Нет внезапных скачков громкости
□ Balance левый/правый каналов в порядке

СИНХРОНИЗАЦИЯ:
□ Переходы на битах
□ Текст синхронизирован с вокалом
□ Кульминация видео = кульминация трека
□ Ритм видео соответствует темпу музыки

ТЕХНИЧЕСКОЕ:
□ Timeline length = длительность трека
□ Framerate: 30 fps (или 60 для smooth)
□ Resolution: 1920×1080 минимум
□ Project settings корректны
```

### Техника 3: Data-moshing (глюк-эффект)

```
В CapCut:
Effects → Video Effects → Glitch → Datamosh

Применение:
- На transition
- На beat drop
- На ошибке/сбое в сюжете

Настройки:
Intensity: 50-70%
Duration: 0.5-1 секунда
```

---

### Техника 4: Loop сегментов

```
ТЕХНИКА:
1. Найдите seamless loop момент (начало = конец)
2. Duplicate клип 2-3 раза
3. Синхронизируйте с repeated секцией в музыке

ПРИМЕР:
Drum loop в музыке (4 бара повторяются)
→ Зациклите визуал тоже (танцор делает движение × 4)

РЕЗУЛЬТАТ: Гипнотический эффект, акцент на repeat
```
