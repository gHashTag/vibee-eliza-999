# Кнопка 📸 Нейрофото - Профессиональные фотосессии артиста

## Введение

Кнопка **📸 Нейрофото** - это ваша цифровая фотостудия с безграничными возможностями. С её помощью вы создадите контент для соцсетей, промо материалы, обложки и любой визуальный контент, который требует профессиональной фотографии вашего артиста.

## Отличия от 🤖 Цифровое тело

### 🤖 Цифровое тело:

- Создание персонажа с нуля
- Полный контроль над внешностью
- Идеально для: первого создания, смены образа, экспериментов

### 📸 Нейрофото:

- Фотосессии существующего персонажа
- Различные локации и стили съемки
- Идеально для: контента соцсетей, промо, серийных публикаций

**Вывод:** Сначала создайте артиста через 🤖 Цифровое тело, затем создавайте контент через 📸 Нейрофото.

## Пошаговая инструкция

### Базовое использование

**Шаг 1: Подготовка референса**

**Что использовать как референс:**

- Лучшее фото из 🤖 Цифровое тело
- Ваше "мастер-изображение" артиста
- Качественный портрет с четким лицом

**Требования:**

- Разрешение: минимум 512x512
- Четкое лицо
- Хорошее освещение
- Формат: JPG или PNG

**Шаг 2: Откройте функцию**

```
Главное меню → 📸 Нейрофото
```

**Шаг 3: Загрузите референс**

```
1. Нажмите "Загрузить фото"
2. Выберите мастер-изображение артиста
3. Дождитесь загрузки
```

**Шаг 4: Напишите промпт локации/стиля**

**Структура промпта:**

```
[описание локации/окружения],
[действие/поза персонажа],
[одежда и стиль],
[освещение],
[атмосфера и настроение],
[стиль фотографии],
[технические параметры]
```

**Шаг 5: Настройка параметров**

**Strength (Сила применения):**

- 0.3-0.4: сохранение лица (рекомендуется)
- 0.5-0.6: средние изменения
- 0.7-0.8: творческая свобода (может изменить лицо)

**Aspect Ratio:**

- 1:1 - Instagram посты
- 9:16 - Stories/Reels
- 4:5 - портретные посты
- 16:9 - YouTube превью

## Оптимизация результатов

### Частые проблемы и решения

**Проблема 1: Лицо меняется слишком сильно**

```
Решения:
✅ Уменьшите Strength до 0.3-0.35
✅ Добавьте в промпт: "maintain exact facial features"
✅ Используйте более четкий референс
✅ Убедитесь что лицо на референсе хорошо освещено
```

**Проблема 2: Одежда/детали не соответствуют промпту**

```
Решения:
✅ Опишите одежду детальнее в промпте
✅ Используйте референс где нужная одежда уже есть
✅ Добавьте вес важным элементам: "(black jacket:1.2)"
✅ Упростите промпт, уберите лишние детали
```

**Проблема 3: Плохое качество изображения**

```
Решения:
✅ Используйте референс высокого разрешения
✅ Добавьте: "8k, highly detailed, sharp focus, professional"
✅ Укажите конкретную камеру: "shot on Sony A7IV"
✅ Проверьте что strength не слишком высокий
```

**Проблема 4: Неправильная атмосфера**

```
Решения:
✅ Детальнее опишите освещение
✅ Добавьте reference художника/стиля
✅ Используйте mood words: "moody, dramatic, energetic"
✅ Укажите технику съемки: "shallow depth of field"
```
