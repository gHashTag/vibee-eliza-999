# ФИНАЛЬНЫЙ ПРОЕКТ: Серия контента артиста

## Введение

Это кульминация всего модуля "Создание артиста". Вы создадите полноценный контент-пакет для музыкального релиза: визуальный образ, промо материалы, контент для соцсетей и медиа-кит. Этот проект покажет, как все изученные инструменты работают вместе.

## Цель проекта

**Создать комплексный визуальный контент для релиза сингла:**

- ✅ 10 уникальных фотографий артиста
- ✅ 5 коротких видео (концепты/анимация)
- ✅ Обложка сингла
- ✅ Промо материалы для соцсетей
- ✅ Пресс-кит
- ✅ Единый визуальный стиль

**Результат:** Полностью готовый контент для запуска музыкального релиза.

## Этап 3: Создание 5 видео концептов (2-3 часа)

```

9-12 сек: Взаимодействие с неоном (Фото 6) → glow effect

```

3. Эффекты: zoom, glow, flash cuts

**Пошаговая сборка:**

1. Импортируйте Фото 2, 3, 4, 6, 1
