# Подготовка к релизу

## Форматы файлов для дистрибуции

### Аудио форматы

**Требования к мастер-файлу:**

- **Формат**: WAV (несжатый)
- **Битрейт**: 16-bit или 24-bit
- **Частота дискретизации**: 44.1 kHz (стандарт CD) или 48 kHz
- **Стерео**: Обязательно
- **Peak уровень**: Не выше -0.1 dB (лучше -1.0 dB для безопасности)
- **True Peak**: Не выше -1.0 dB TP
- **Динамический диапазон**: Минимум DR7, рекомендуется DR10-14

**Почему WAV?**

- Без потерь качества
- Универсальная совместимость
- Стандарт индустрии

**Конвертация из других форматов:**

```
MP3 → WAV ❌ (не улучшит качество!)
FLAC → WAV ✅ (без потерь)
AIFF → WAV ✅ (эквивалентно)
```

### Технические параметры

**Loudness Standards:**

- **Spotify**: -14 LUFS integrated
- **Apple Music**: -16 LUFS integrated
- **YouTube**: -13 to -15 LUFS
- **Tidal**: -14 LUFS
- **TikTok/Instagram**: -12 to -14 LUFS

**Рекомендация**: Мастерируйте на -14 LUFS как золотую середину.

**Частотный диапазон:**

- **Low-end**: Контролируйте sub-bass ниже 30 Hz
- **High-end**: Срежьте всё выше 20 kHz
- **Mid-range**: Чистота вокала (1-4 kHz)

**Длительность:**

- **Минимум**: 30 секунд для большинства сервисов
- **Оптимум**: 2:30 - 3:30 (современные стандарты)
- **Fade-out**: 2-5 секунд, если используется

## Метаданные

### Обязательные поля

**Основная информация:**

- Название трека (Title)
- Имя исполнителя (Artist/Primary Artist)
- Название альбома (Album/Release Title)
- Жанр (Genre) - выберите основной + до 2 дополнительных
- Год выпуска (Release Year)
- Авторские права (℗ Copyright Line): "© 2024 Your Name"
- Лейбл (Label): Можете указать своё имя как независимый артист

**Дополнительная информация:**

- Текст песни (Lyrics) - увеличивает шансы попадания в плейлисты
- Язык (Language)
- Explicit content: Да/Нет
- Featured artists (если есть коллаборации)
- Composer/Songwriter credits
- Producer credits

### Жанры и стили

**Популярные категории для AI-музыки:**

- **Electronic**: Ambient, Chillout, Lo-fi, Future Bass
- **Pop**: Indie Pop, Synth-pop, Dream Pop
- **Hip-Hop/Rap**: Lo-fi Hip-Hop, Trap, Boom Bap
- **Alternative**: Alternative/Indie, Experimental
- **R&B/Soul**: Contemporary R&B, Neo-Soul

**Выбор жанра - стратегия:**

- Основной жанр = самая большая аудитория
- Поджанр = точное позиционирование
- Избегайте слишком узких категорий (менее 10k слушателей)

### Обложка альбома

**Технические требования:**

- **Размер**: 3000x3000 пикселей (минимум)
- **Формат**: JPG или PNG
- **Цветовой профиль**: RGB (не CMYK!)
- **Размер файла**: Не более 10 MB
- **Качество**: 300 DPI для печати

**Дизайн - правила:**

- ❌ Нельзя: Контактную информацию (email, соцсети)
- ❌ Нельзя: Цены и даты
- ❌ Нельзя: Чужие логотипы без разрешения
- ❌ Нельзя: Размытое или низкокачественное изображение
- ✅ Можно: Логотип артиста
- ✅ Можно: Название релиза
- ✅ Можно: Абстрактный/оригинальный арт

**AI-генерация обложек:**

- **Midjourney**: Высокое качество, $10-30/мес
- **DALL-E 3**: $20 за 115 изображений
- **Stable Diffusion**: Бесплатно, но требует навыков
- **Canva**: Шаблоны + AI-элементы, от $0

**Промпт для обложки:**

```
album cover art, [жанр музыки] style, minimalist design,
vibrant colors, abstract [тема песни], professional photography,
high contrast, clean composition, modern aesthetic, 4k quality
```

## Юридические аспекты

### Авторские права

**Что вы автоматически получаете:**

- ©️ Copyright на записанную композицию (Sound Recording)
- Права на мастер-запись (Master Rights)
- Авторские права на мелодию и текст (если сами написали)

**AI-музыка и авторские права:**

- ✅ Вы владеете правами на финальную композицию
- ⚠️ Проверьте Terms of Service AI-сервиса (Suno, Udio)
- ⚠️ Некоторые AI-платформы требуют указания "AI-generated"
- ✅ Если вы добавили собственный вокал/инструменты = 100% ваша

**Регистрация авторских прав:**

- **США**: US Copyright Office ($35-65)
- **Россия**: РАО (Российское Авторское Общество)
- **Международная защита**: Берлинская конвенция (автоматическая в 179 странах)

**Нужно ли регистрировать?**

- Авторство возникает автоматически при создании
- Регистрация = дополнительная защита в суде
- Для большинства начинающих: необязательно

### Семплирование и сэмплы

**Использование чужой музыки:**

- ❌ Нельзя: Использовать узнаваемые сэмплы без разрешения
- ❌ Нельзя: Кавер-версии без лицензии
- ✅ Можно: Royalty-free сэмплы (проверьте лицензию!)
- ✅ Можно: AI-генерация (обычно OK, но читайте ToS)

**Безопасные источники сэмплов:**

- Splice (royalty-free, от $9.99/мес)
- Loopcloud (royalty-free)
- Freesound.org (проверяйте лицензию каждого файла)
- AI-генерированные мелодии (Suno, Udio)

**Лицензии Creative Commons:**

- **CC0**: Полностью свободно
- **CC BY**: Требуется указание автора
- **CC BY-NC**: Только некоммерческое использование (⚠️ не подходит для дистрибуции!)

### PRO (Performance Rights Organizations)

**Что это:**
Организации, собирающие роялти за публичное исполнение вашей музыки.

**Основные PRO:**

- **США**: BMI (бесплатно), ASCAP ($50), SESAC (только по приглашению)
- **Россия**: РАО
- **Европа**: PRS (UK), GEMA (Germany), SACEM (France)

**Нужно ли регистрироваться:**

- ✅ Да, если хотите получать роялти от радио, ТВ, кафе
- ⏳ Можно подождать до первых 10k прослушиваний
- 💰 PRO забирает 10-15% комиссии

## ISRC коды

### Что такое ISRC

**ISRC** (International Standard Recording Code) = уникальный штрих-код для каждого трека.

**Формат:**

```
US-S1Z-99-00001
│  │ │  │  └──── Порядковый номер записи
│  │ │  └─────── Год регистрации кода
│  │ └────────── Код регистранта
│  └─────────── Страна
```

**Зачем нужен:**

- Отслеживание прослушиваний
- Получение роялти
- Защита от плагиата
- Аналитика по платформам

### Как получить ISRC

**Вариант 1: Через дистрибьютора (рекомендуется)**

- DistroKid: Автоматически генерирует бесплатно ✅
- TuneCore: Автоматически включено ✅
- CD Baby: Автоматически ✅

**Вариант 2: Самостоятельная регистрация**

- **США**: US ISRC Agency (бесплатно)
- **Россия**: MФИАП (Московская Федерация Интеллектуальной Собственности)
- **Международная**: Через национальное агентство страны

**Когда использовать:**

- Каждая уникальная запись = отдельный ISRC
- Ремикс = новый ISRC
- Ремастер = новый ISRC (опционально)
- Одна и та же версия на разных альбомах = тот же ISRC

## Чеклист перед релизом

### За 4-6 недель до релиза

- [ ] Финальный мастеринг завершён
- [ ] Создан файл WAV 16-bit/44.1kHz
- [ ] Loudness проверен (-14 LUFS)
- [ ] Обложка готова (3000x3000, RGB, JPG/PNG)
- [ ] Метаданные собраны (название, жанр, credits)
- [ ] Lyrics набраны (если есть текст)
- [ ] Выбран дистрибьютор
- [ ] Зарегистрирован аккаунт дистрибьютора

### За 3-4 недели

- [ ] Загружен трек на дистрибьютора
- [ ] Выбрана дата релиза (минимум +2-3 недели)
- [ ] ISRC код получен/назначен
- [ ] UPC код для альбома (если применимо)
- [ ] Выбраны платформы для дистрибуции
- [ ] Pre-save campaign создана (Spotify, Apple Music)

### За 2 недели

- [ ] Отправлен питч в Spotify Editorial (если это первый релиз на Spotify)
- [ ] Создан контент для соцсетей:
  - Тизеры (15-30 сек)
  - Instagram Stories шаблоны
  - TikTok превью
- [ ] Пресс-релиз написан (опционально)
- [ ] Создан плейлист с похожими треками + ваш

### За 1 неделю

- [ ] Проверен статус релиза на дистрибьюторе (Approved/Pending)
- [ ] Финальная проверка метаданных
- [ ] Контент запланирован в соцсетях
- [ ] Email подготовлен для рассылки (если есть база)
- [ ] Контакт с плейлист-кураторами (SubmitHub, Playlist Push)

### День релиза

- [ ] Проверить появление на всех платформах (8-12 часов может занять)
- [ ] Опубликовать анонс в соцсетях
- [ ] Отправить ссылки друзьям/фанам
- [ ] Добавить трек в свои плейлисты
- [ ] Мониторить первые отзывы
- [ ] Ответить на первые комментарии

### После релиза (первая неделя)

- [ ] Ежедневный мониторинг Spotify for Artists
- [ ] Ответы на комментарии
- [ ] Продолжение продвижения (Stories, Reels)
- [ ] Отслеживание плейлистов, куда добавили трек
- [ ] Сбор первых данных аналитики
