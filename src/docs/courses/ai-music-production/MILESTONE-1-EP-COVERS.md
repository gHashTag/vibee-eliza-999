# 🏆 MILESTONE 1: Создай 5 Обложек для EP

**После прохождения:** Модуль 1 - AI-генерация изображений

## 🎯 Цель

Создать серию из 5 обложек в едином стиле для воображаемого EP

## 📋 Задание

### 1️⃣ Придумай концепцию EP

Заполни свою концепцию:

- **Название EP:** "**\*\***\_\_\_**\*\***"
- **Жанр:** **\*\***\_\_\_**\*\*** (например: Lo-fi Hip-Hop, Synthwave, Ambient)
- **Настроение:** **\*\***\_\_\_**\*\*** (например: melancholic, energetic, dreamy)
- **Ключевые визуальные элементы:** **\*\***\_\_\_**\*\***

### 2️⃣ Создай 5 обложек

**Cover 1: Main EP Cover**

- Главная обложка для всего EP
- Должна отражать общую концепцию
- Самая впечатляющая из серии

**Covers 2-5: Individual Track Covers**

- Track 1: "**\*\***\_\_\_**\*\***"
- Track 2: "**\*\***\_\_\_**\*\***"
- Track 3: "**\*\***\_\_\_**\*\***"
- Track 4: "**\*\***\_\_\_**\*\***"

Каждая обложка должна:

- Быть уникальной
- Сохранять единый стиль с главной
- Отражать настроение трека

### 3️⃣ Единый стиль

Определи свой фирменный стиль:

**Цветовая палитра:**

- Основной цвет: #**\_\_**
- Дополнительный цвет: #**\_\_**
- Акцентный цвет: #**\_\_**

**Typography style:**

- Шрифт для названия: **\*\***\_\_\_**\*\***
- Размер: **\*\***\_\_\_**\*\***
- Расположение: **\*\***\_\_\_**\*\***

**Visual motifs:**

- Повторяющиеся элементы: **\*\***\_\_\_**\*\***
- Композиция: **\*\***\_\_\_**\*\*** (центральная, диагональная, симметричная)
- Текстура/эффекты: **\*\***\_\_\_**\*\***

## 📝 Пошаговый план

### День 1: Концепция и исследование (30 минут)

- [ ] Выбери жанр и настроение
- [ ] Изучи 10-15 обложек в этом стиле на Spotify
- [ ] Создай mood board (сохрани референсы)
- [ ] Запиши ключевые слова для промптов

### День 2: Main Cover (45 минут)

- [ ] Напиши промпт для главной обложки
- [ ] Сгенерируй 5-10 вариантов
- [ ] Выбери лучший
- [ ] Upscale до 3000x3000px
- [ ] Добавь текст (название EP)

### День 3: Track Covers (1 час)

- [ ] Создай обложку для Track 1
- [ ] Создай обложку для Track 2
- [ ] Создай обложку для Track 3
- [ ] Создай обложку для Track 4
- [ ] Upscale все 4 обложки

### День 4: Финализация (15 минут)

- [ ] Проверь единство стиля
- [ ] Добавь текст на все обложки
- [ ] Экспортируй в правильном формате
- [ ] Создай mockup для портфолио

## ✅ Критерии успеха

### Технические требования

- [ ] 5 обложек созданы
- [ ] Разрешение каждой: минимум 3000x3000px
- [ ] Формат: PNG или JPG высокого качества
- [ ] Готовы для загрузки на Spotify/Apple Music

### Визуальное единство

- [ ] Единая цветовая палитра во всех 5 обложках
- [ ] Консистентный typography style
- [ ] Повторяющиеся визуальные мотивы
- [ ] Все обложки узнаваемо из одной серии

### Профессиональное качество

- [ ] Обложки выглядят профессионально
- [ ] Текст читабельный на маленьких размерах
- [ ] Композиция сбалансирована
- [ ] Можно использовать для реального релиза

## 💰 Бюджет

### Stars (Telegram Stars)

- 5 covers × 9⭐ (SeeDream 4K) = 45⭐
- 5 upscales × 2⭐ (Magnific) = 10⭐
- Текстовые эксперименты = 5⭐
- **Итого: ~60⭐ (~$0.96)**

### Альтернатива (экономия)

- Используй 2K вместо 4K: 5 × 6⭐ = 30⭐
- Используй встроенный upscale: 0⭐
- **Итого: ~30⭐ (~$0.48)**

## ⏱️ Время

**Быстрый трек:** 2-3 часа за один день
**Рекомендуемый:** 4 дня по 30-60 минут

## 📤 Как сдать проект

1. Создай папку с результатами:

   ```
   milestone-1-ep-covers/
   ├── concept.txt (твоя концепция)
   ├── main-cover.png (3000x3000)
   ├── track-1-cover.png
   ├── track-2-cover.png
   ├── track-3-cover.png
   ├── track-4-cover.png
   └── mockup.png (необязательно)
   ```

2. Заполни чеклист успеха
3. Поделись в чате курса (получи фидбек)
4. Получи Achievement Badge
