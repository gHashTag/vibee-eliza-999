## 📝 Пошаговый план

### Неделя 1: Подготовка (1 час)

**День 1: Storyboard (30 минут)**

- [ ] Нарисуй или опиши 6 ключевых кадров
- [ ] Определи движение камеры для каждой сцены
- [ ] Выбери музыку (30 секунд из твоего воображаемого трека)

**День 2: Reference gathering (30 минут)**

- [ ] Найди 5-10 референсных видео в твоем стиле
- [ ] Изучи типы camera movements
- [ ] Запиши ключевые слова для промптов

### Неделя 2: Генерация (3-4 часа)

**День 3-4: Scenes 1-3 (2 часа)**

- [ ] Сгенерируй Scene 1 (3-5 попыток для лучшего варианта)
- [ ] Сгенерируй Scene 2 (учитывая переход от Scene 1)
- [ ] Сгенерируй Scene 3
- [ ] Upscale лучшие варианты

**День 5-6: Scenes 4-6 (2 часа)**

- [ ] Сгенерируй Scene 4
- [ ] Сгенерируй Scene 5
- [ ] Сгенерируй Scene 6 (финальный кадр - самый сильный)
- [ ] Upscale финальные версии

### Неделя 3: Сборка (1-2 часа)

**День 7: Editing (1 час)**

- [ ] Импортируй все сцены в видеоредактор
- [ ] Синхронизируй с музыкой
- [ ] Добавь transitions между сценами
- [ ] Цветокоррекция для единства

**День 8: Финализация (1 час)**

- [ ] Добавь title card в начале
- [ ] Добавь credits в конце
- [ ] Экспортируй в 1080p или 4K
- [ ] Создай thumbnail для видео

## ✅ Критерии успеха

### Технические требования

- [ ] Длительность: 30 секунд (±2 секунды)
- [ ] Разрешение: минимум 1080p (1920x1080)
- [ ] Формат: MP4, H.264
- [ ] Частота кадров: 24fps или 30fps
- [ ] Качество звука: 320kbps

### Творческие критерии

- [ ] Визуально связано с обложкой из Milestone 1
- [ ] Плавные переходы между сценами
- [ ] Синхронизация с музыкой
- [ ] Единый визуальный стиль
- [ ] Профессиональный вид

### Storytelling

- [ ] Есть начало, развитие, кульминация
- [ ] Визуальная прогрессия соответствует музыке
- [ ] Финальная сцена оставляет впечатление
- [ ] Можно понять настроение без звука

## 🎯 Pro Tips

### Camera Movements для AI

**Эффективные промпты:**

```
"slow zoom in"
"camera dolly forward"
"gentle pan left to right"
"orbital rotation around subject"
"crane shot moving up"
"tracking shot following movement"
```

### Consistency техники

1. **Используй Image-to-Video:**

   - Сгенерируй keyframe изображения
   - Затем создавай видео из них
   - Больше контроля над стилем

2. **Reference frames:**

   - Используй последний кадр Scene 1 как референс для Scene 2
   - Создаёт плавные переходы

3. **Style tokens:**
   - Добавляй в каждый промпт: "in [your style] style"
   - Например: "in neon retrowave style"
