## 📋 Формат навигации

Каждый урок теперь содержит в конце:

```markdown
---

## 🧭 Навигация

📍 **Вы здесь:** [Модуль X: НАЗВАНИЕ](../README.md) → Урок X.Y

| ⬅️ Предыдущий | 📚 Оглавление | Следующий ➡️ |
|:---|:---:|---:|
| [Название предыдущего урока](./XX-НАЗВАНИЕ.md) | [📋 Главное меню](../ОГЛАВЛЕНИЕ.md) | [Название следующего урока](./XX-НАЗВАНИЕ.md) |

**Прогресс модуля:** `[████░░░] XX% (Y/Z уроков)`

**Связанные уроки:**
- 🔗 [Prerequisite] Урок X.X - Название
- 🔗 [Рекомендуется] Урок Y.Y - Название
- 🔗 [Milestone проект] MILESTONE-X.md

---
```

## 🎯 Особенности реализации

### 1. Адаптивный прогресс-бар

- Визуальный индикатор прогресса модуля
- Процент завершения
- Текущий урок / Всего уроков
- ✅ чекмарк при 100% завершении

### 2. Умная навигация

- **Первый урок модуля**: Предыдущий → ОГЛАВЛЕНИЕ.md
- **Последний урок модуля**: Следующий → первый урок следующего модуля
- **Промежуточные уроки**: Навигация внутри модуля

### 3. Связанные уроки

- **[Prerequisite]**: Обязательные для изучения до текущего урока
- **[Рекомендуется]**: Полезные для понимания материала
- **[Milestone проект]**: Финальный проект модуля
