## 🎨 Стандарты Визуальных Элементов

### Технические Требования

#### Скриншоты Интерфейса:

- **Разрешение**: 1920x1080px (Full HD)
- **Формат**: PNG с прозрачностью где нужно
- **Язык**: Русский интерфейс
- **Качество**: Без сжатия, четкий текст
- **Выделения**: Красные рамки/стрелки для важных элементов

#### Примеры Результатов (обложки, видео):

- **Разрешение**: Оригинальное качество моделей
  - Обложки: 1024x1024px (FLUX)
  - Видео: 1280x720px или 1920x1080px
- **Формат**: JPG для обложек, MP4 для видео
- **Watermark**: Добавить тонкий watermark бота (опционально)

#### Диаграммы и Схемы:

- **Инструмент**: Figma, Miro, или draw.io
- **Стиль**: Минималистичный, чистый
- **Цветовая схема**:
  - Основной: #6366F1 (индиго)
  - Акцент: #F59E0B (янтарный)
  - Текст: #1F2937 (темно-серый)
- **Шрифт**: Inter или системный sans-serif
- **Формат**: SVG (векторный) или PNG 2x resolution

## 🎬 Гайд по Созданию Скриншотов

### Для Интерфейса Telegram Бота:

**Инструменты:**

- Telegram Desktop (лучшее качество)
- Cleanshot X / Snagit (для аннотаций)
- Figma (для финальной обработки)

**Процесс:**

1. Открыть бота в Telegram Desktop
2. Установить язык интерфейса = Русский
3. Очистить чат от лишних сообщений
4. Сделать скриншот нужного меню/экрана
5. В Figma добавить красные рамки/стрелки на важные элементы
6. Экспортировать PNG 2x

**Чеклист качества:**

- ✅ Текст читается четко
- ✅ Важные элементы выделены
- ✅ Нет лишней информации в кадре
- ✅ Соотношение сторон правильное
- ✅ Имя файла описательное (01-main-menu.png)

---

### Для Примеров Работ:

**Процесс:**

1. Сгенерировать пример в боте
2. Скачать результат в оригинальном качестве
3. При необходимости добавить подпись (модель, промпт, цена)
4. Сохранить с метаданными (prompt в описании файла)

**Категории примеров:**

- 🎨 **Обложки**: Lo-Fi, Hip-Hop, Electronic, Rock, Indie
- 🎬 **Видео**: По 1 примеру каждой модели (Sora, Kling, Haiper)
- 👤 **Персонажи**: Разные стили и ракурсы
- 🔄 **Морфинги**: Цепочки трансформаций
