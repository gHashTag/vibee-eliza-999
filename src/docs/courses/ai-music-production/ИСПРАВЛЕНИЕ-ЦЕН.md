### 🚨 КРИТИЧЕСКОЕ #1: Haiper Video 2

**Проблема:** Разница в **460x раз** между уроками!

**Источник проблемы:**

- **Файл 1:** `03-КНОПКА-ВИДЕО-ИЗ-ТЕКСТА-ВСЕ-МОДЕЛИ.md` (строка 57)

  ```markdown
  ### 2. Haiper Video 2 (0.05⭐) - Лучшее качество/цена

  💰 Цена: 0.05 звезды (ДЕШЕВО!)
  ```

  **ОШИБКА:** Указана базовая стоимость в USD ($0.05), а не в звездах!

- **Файл 2:** `03-КНОПКА-ВИДЕО-ИЗ-ТЕКСТА-УПРОЩЕННАЯ.md` (строка 62)

  ```markdown
  ### 2. 🌟 Haiper Video 2 (23⭐) - Универсальная модель

  💰 Цена: 23 звезды за 5 секунд (4.60⭐/сек)
  ```

  **НО:** Цена 23⭐ не соответствует ни одной конфигурации!

**ИСТИНА из кода:**

```typescript
// modelsCost.ts
HaiperVideo: 0.6  // ~38⭐ базовая цена

// Расчет:
baseCostUSD = 0.6
stars = Math.floor((0.6 / 0.016) * 1.5) = Math.floor(56.25) = 56⭐

// НО комментарий в коде говорит ~38⭐
// Это значит используется СТАРАЯ наценка без 1.5x!
stars_old = 0.6 / 0.016 = 37.5 ≈ 38⭐
```

**РЕШЕНИЕ:**

- Принимаем **официальную цену из modelsCost.ts: 38⭐**
- Исправляем 0.05⭐ → 38⭐ во ВСЕХ упоминаниях

### ⚠️ ПРОБЛЕМА #2: Несоответствие цен Replicate vs Kie.ai

**Обнаружено:** Курс смешивает модели из двух разных API:

1. **Replicate API** (Haiper, Ray-v2, Minimax, Wan)
2. **Kie.ai API** (Sora 2, Runway Aleph, Kling, Veo)

**Правильный подход:**

- **Для Видео из текста:** Преимущественно **Kie.ai модели** (Sora 2, Kling Pro)
- **Для Фото в видео:** Преимущественно **Replicate модели** (Haiper, Ray-v2)
