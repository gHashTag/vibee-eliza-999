# 🎨 Реализация генератора аватаров DiceBear

## Выполненные задачи

### 1. ✅ Установка библиотеки DiceBear
```bash
npm install @dicebear/avatars @dicebear/avatars-avataaars-sprites @dicebear/avatars-human-sprites @dicebear/avatars-initials-sprites --legacy-peer-deps
```

Установлены все необходимые пакеты:
- `@dicebear/avatars` - основная библиотека
- `@dicebear/avatars-avataaars-sprites` - стиль аватаров
- `@dicebear/avatars-human-sprites` - стиль людей
- `@dicebear/avatars-initials-sprites` - стиль инициалов

### 2. ✅ Компонент AvatarGenerator
**Файл:** `src/components/avatar-generator.tsx`

Возможности:
- 3 стиля: Avataaars, Human, Initials
- Предпросмотр аватара в реальном времени
- Интерактивные кнопки для смены стиля
- Кнопка "Обновить аватар" для генерации нового варианта
- Золотистая цветовая схема (#ffd700, #ffc700, #ffb700, #ffdd55, #ffe066, #ffed4a)
- Настраиваемый размер (по умолчанию 200x200)
- Отображение сида (первые 8 символов)

### 3. ✅ Страница создания агента
**Файл:** `src/pages/create-agent.tsx`

Функционал:
- Разделенная верстка: превью аватара слева, настройки справа
- Интеграция с компонентом AvatarGenerator
- Форма с полями:
  - Имя агента (обязательное)
  - Описание (опциональное)
  - Выбор стиля аватара
- Кнопка "Случайный аватар"
- Кнопка "Создать агента"
- Навигация назад к списку агентов

### 4. ✅ Маршрут в приложении
**Файл:** `src/App.tsx`

Добавлен маршрут:
```typescript
<Route path="/create" element={<CreateAgentPage />} />
```

### 5. ✅ Утилита для получения аватаров
**Файл:** `src/lib/utils.ts`

Функция `getAgentAvatar()`:
- Проверяет наличие существующего аватара в настройках агента
- Генерирует уникальный аватар для каждого агента на основе его ID или имени
- Детерминированный выбор стиля (хэш от имени агента)
- Автоматическая генерация SVG с золотистой цветовой схемой
- Все существующие и новые агенты получают уникальные аватары

## Цветовая схема

Все аватары используют золотистую палитру в стиле VIBEE:
- `#ffd700` (золотой)
- `#ffc700` (золотисто-желтый)
- `#ffb700` (темно-золотистый)
- `#ffdd55` (светло-золотистый)
- `#ffe066` (лимонно-золотистый)
- `#ffed4a` (желто-золотистый)

## Использование

### Создание нового агента с аватаром
1. Перейти на страницу `/create`
2. Ввести имя агента
3. Выбрать стиль аватара (или оставить случайный)
4. Нажать "Случайный аватар" для генерации нового
5. Нажать "Создать агента"

### Генерация аватара в коде
```typescript
import { getAgentAvatar } from '@/lib/utils';

const avatarUrl = getAgentAvatar(agent);
// Возвращает SVG строку с уникальным аватаром агента
```

### Использование компонента AvatarGenerator
```typescript
import { AvatarGenerator } from '@/components/avatar-generator';

<AvatarGenerator
  seed="agent-name"
  style="avataaars"
  size={200}
  onAvatarGenerated={(dataUri) => console.log(dataUri)}
  showControls={true}
/>
```
