## ⚠️ ВАЖНЫЕ МОМЕНТЫ

1. **ElizaOS = ОДИН процесс = ОДИН агент = ОДИН порт**
   - Каждый агент требует отдельный процесс
   - Каждый агент требует свой порт
   - Нельзя запустить "всех в одном"

2. **Клиент тоже отдельный процесс**
   - Клиент на localhost:5173 (Vite dev server)
   - Агенты на localhost:3000-3003 (ElizaOS server)

3. **Правильный процесс запуска:**
   - 1. Кастомный клиент (npm run dev в vibee-client/)
   - 2. Каждый агент (PORT=XXXX npx elizaos start --character...)
   - 3. Итого: 1 клиент + 4 агента = 5 процессов

4. **Порты агентов:**
   - 3000 - VIBEE (главный)
   - 3001 - Instagram Expert
   - 3002 - KOLS Agent
   - 3003 - NeuroPhoto Agent
   - 5173 - Кастомный клиент
