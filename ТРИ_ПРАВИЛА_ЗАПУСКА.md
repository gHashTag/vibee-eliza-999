# 🚨 ЧЕТЫРЕ КРИТИЧЕСКИХ ПРАВИЛА ЗАПУСКА VIBEE

## 📌 ПРАВИЛО №1: БАЗА ДАННЫХ - ВСЕГДА POSTGRESQL!
**МЫ ВСЕГДА ИСПОЛЬЗУЕМ ОДНУ БАЗУ ДАННЫХ - PostgreSQL!**

✅ **ПРАВИЛЬНО:** ВСЕГДА используйте PostgreSQL:
```bash
# В .env.dev ОБЯЗАТЕЛЬНО должно быть:
DATABASE_URL=postgresql://neondb_owner:npg_A9z2dErbkfhw@ep-bitter-frog-a1bewei7-pooler.ap-southeast-1.aws.neon.tech/neondb?sslmode=require&channel_binding=require

# В скриптах запуска ОБЯЗАТЕЛЬНО экспортируйте POSTGRES_URL!
export POSTGRES_URL="postgresql://neondb_owner:npg_A9z2dErbkfhw@ep-bitter-frog-a1bewei7-pooler.ap-southeast-1.aws.neon.tech/neondb?sslmode=require&channel_binding=require"
export DATABASE_URL="$POSTGRES_URL"

# Разрешаем деструктивные миграции для PostgreSQL
export ELIZA_ALLOW_DESTRUCTIVE_MIGRATIONS=true
```

**🔑 КРИТИЧЕСКИ ВАЖНО:**
1. **SQL плагин ElizaOS ищет именно `POSTGRES_URL`**, а не `DATABASE_URL`!
   - Если `POSTGRES_URL` не установлен → плагин использует PGLite (SQLite) по умолчанию
   - Если `POSTGRES_URL` установлен → плагин использует PostgreSQL

2. **`ELIZA_ALLOW_DESTRUCTIVE_MIGRATIONS=true` обязательна** для запуска миграций в PostgreSQL
   - Без неё агенты не смогут создать таблицы и схемы

❌ **НЕПРАВИЛЬНО:** Использовать PGLite, SQLite или любые другие базы
❌ **НЕПРАВИЛЬНО:** Удалять POSTGRES_URL из переменных окружения
❌ **НЕПРАВИЛЬНО:** Запускать без ELIZA_ALLOW_DESTRUCTIVE_MIGRATIONS
❌ **НЕПРАВИЛЬНО:** Переключаться между базами

**ВАЖНО: ОДНА БАЗА ДЛЯ ВСЕХ - И В ПРОДАКШЕНЕ, И ЛОКАЛЬНО!**

## 📌 ПРАВИЛО №2: МНОЖЕСТВЕННЫЕ АГЕНТЫ
**ElizaOS НЕ поддерживает множественные агенты в одном процессе!**

❌ **НЕПРАВИЛЬНО:** `elizaos start` (запускает ОДИН агент)
✅ **ПРАВИЛЬНО:** Каждый агент в отдельном процессе + свой порт:
```bash
# Терминал 1: Главный агент VIBEE (порт 3000)
PORT=3000 npx elizaos start --character /Users/playra/vibee-agent/characters/vibeeAgent.json

# Терминал 2: Instagram Expert (порт 3001)
PORT=3001 npx elizaos start --character /Users/playra/vibee-agent/characters/instagramExpert.json

# Терминал 3: KOLS Agent (порт 3002)
PORT=3002 npx elizaos start --character /Users/playra/vibee-agent/characters/kolsAgent.json

# Терминал 4: NeuroPhoto Agent (порт 3003)
PORT=3003 npx elizaos start --character /Users/playra/vibee-agent/characters/neuroPhoto.json
```

## 📌 ПРАВИЛО №3: КАСТОМНЫЙ КЛИЕНТ
**Кастомный клиент ДОЛЖЕН быть запущен отдельно от агентов!**

✅ **ПРАВИЛЬНО:** В отдельном терминале:
```bash
cd /Users/playra/vibee-agent/vibee-client
npm run dev
# Запускается на: http://localhost:5173
```

**Порты:**
- 🔵 Агент (ElizaOS): http://localhost:3000
- 🟡 Кастомный клиент: http://localhost:5173
- 🟢 Разные процессы = разные порты

## 📌 ПРАВИЛО №4: ПРАВИЛЬНЫЙ СКРИПТ ЗАПУСКА
**НЕ используйте старые скрипты - они запускают только ОДИН агент!**

❌ **НЕПРАВИЛЬНО:**
- `bun dev` (запускает ОДИН агент)
- `scripts/dev-with-infisical.sh` (запускает ОДИН агент)

✅ **ПРАВИЛЬНО - Используйте этот скрипт:**
```bash
#!/bin/bash
# Файл: scripts/start-all.sh

echo "🚀 Запуск всех компонентов VIBEE..."

# 1. Запускаем кастомный клиент в фоне
cd /Users/playra/vibee-agent/vibee-client
npm run dev &
CLIENT_PID=$!
echo "✅ Кастомный клиент запущен (PID: $CLIENT_PID) на http://localhost:5173"

# 2. Останавливаем старые процессы elizaos
pkill -f "elizaos" 2>/dev/null
sleep 2

# 3. Запускаем всех агентов в отдельных терминалах/процессах
cd /Users/playra/vibee-agent

echo ""
echo "📋 Запускаем агентов:"
echo "  1. VIBEE (главный)"
npx elizaos start --character characters/vibeeAgent.json &
sleep 3

echo "  2. Instagram Expert"
npx elizaos start --character characters/instagramExpert.json &
sleep 3

echo "  3. KOLS Agent"
npx elizaos start --character characters/kolsAgent.json &
sleep 3

echo "  4. NeuroPhoto Agent"
npx elizaos start --character characters/neuroPhoto.json &
sleep 3

echo ""
echo "🎉 ВСЕ ЗАПУЩЕНО!"
echo "📊 Статус:"
echo "  🔵 Агент VIBEE: http://localhost:3000"
echo "  🟡 Кастомный клиент: http://localhost:5173"
echo ""
echo "⏹️  Для остановки: pkill -f 'elizaos' && pkill -f 'vite'"
```

## 🔧 ПРОВЕРКА СТАТУСА

**Проверить всех агентов:**
```bash
ps aux | grep "elizaos start" | grep -v grep
```

**Проверить кастомный клиент:**
```bash
ps aux | grep "vite" | grep -v grep
```

**Проверить порты:**
```bash
# Агент
curl -s http://localhost:3000/health | head -5

# Клиент
curl -s http://localhost:5173 | head -5
```

## ⚠️ ВАЖНО!

1. **Каждый агент = отдельный процесс**
2. **Клиент = отдельный процесс**
3. **Общий процесс = 1 агент + 1 клиент = 2 процесса**
4. **Для 4 агентов = 4 процесса агентов + 1 клиент = 5 процессов**

**💡 Запомните: ElizaOS - это НЕ многопользовательская система! Каждый агент работает в своем изолированном процессе.**
